# 火鸡开屏大赛 · 两章十关（v0.5）

第一章：感恩节前夜，火鸡们一路赶往「火鸡赦免大会」，开屏最美的火鸡被赦免，其余的今晚上餐桌。第二章：感恩节当天，被赦免的火鸡回去救伙伴，最后带着大家逃向自由。左右拖动带火鸡奔跑，吃羽毛让尾巴开屏越来越大，终点上台开屏、评委打分、发赦免证书。

参考：《Hair Challenge》（收集变长跑酷）与《Count Masters》（加减乘除门）。只借鉴结构，人物、关卡、模型、代码原创。感恩节元素取自美国“总统赦免火鸡”的传统（游戏内不使用任何真实人物或机构形象）。

## 打开
双击工作区根目录「启动火鸡开屏大赛.cmd」，默认 http://localhost:8931/ 。

- 拿到 ≥1 星解锁下一关；每关记录最高星数与最佳分。结算页可直接进入下一关。
- 难度梯度（`src/levels.mjs`）：跑速 9.5→12.8、危险移动速度 ×1.0→×1.6、羽毛段更密、动脑门（两扇蓝门挑更划算的 / 两扇红门取其轻）0→45%、连续两个危险 0→75%；门的数值和 ×门数量逐关变大，高手羽毛数约 78→98→132→159→191→229→252→266→275→298（上限 320）。赛道种子用 `tools/seedsearch.mjs` 挑过，`tools/calib.mjs` 输出各水平机器人的分数与星级。

## 评分（满分 30）
三位评委各看一项，各 10 分：
- 小黄 · 尾屏：羽毛数 / 本关目标，越多越高但边际递减（到目标约 9.2，1.3 倍约 9.6）。
- 老白 · 色彩：颜色种类为主（6 色齐），再看各色是否均匀。
- 小粉 · 台风：从 10 扣起——每被撞一次 −1.3，每扇门选亏 −0.9，路上羽毛漏吃按比例最多 −4。
星级：≥27 三星，≥22 两星，≥15 一星（发赦免证书）。结算页列出三项分和扣分原因。

## 玩法
- 一根手指左右拖动（电脑可用 ← →）。
- 吃彩色羽毛：尾屏多一根、开屏变大。六种丰收色：蔓越莓红、南瓜橙、玉米金、鼠尾草绿、葡萄紫、丰收彩虹。
- 门：蓝门加/乘，红门减/除，二选一；第 2 关起有“动脑门”，第 3 关起部分门会左右滑动。
- 危险：禽类剪刀剪约 30%；大厨抢一半；大南瓜、大叉子撞掉 25%；南瓜派糊脸掉 20%；土豆泥掉 15% 并减速。有伙伴时由伙伴挡（大厨吓跑 3 只，其他 2 只）。
- 终点：火鸡上台转身开屏，三位小鸡评委亮分（满分 30），≥1 星发赦免证书。

## 画面
- 火鸡：沿椭球表面实例化的约 200 片 3D 古铜覆羽、贴身绶带勋章、外露大眼睛；尾屏同心多层整齐排列，羽毛很多时外圈放在后面，不挡脸。
- 场景按主题切换天空渐变、太阳、云色、星空、雾、半球光/主光/补光、曝光和辉光；夜晚关卡有跟随火鸡的追光。
- 后期：MSAA + 三级辉光 + ACES + 轻微 S 曲线对比 + 暗角。
- 镜头：按尾屏实际高度抬高、后退，跑动时尾屏略收小并后仰（终点再完全展开），前方约 11m 外的路面和障碍始终露在尾屏上方；俯仰角按视场计算，火鸡脚下固定在画面约 80% 高度，横竖屏都不出画。
- 观众：每人有眼睛、笑嘴、腮红和帽子/头发（同一实例列表，欢呼跳动时同步）。
- 性能：重复物件实例化并按 40m 分块剔除；立面/招牌用图集合并；同一关重玩不重建场景。桌面 RTX 4060 Ti 每关约 11–19 ms/帧（2048×1536）；手机未实测。
