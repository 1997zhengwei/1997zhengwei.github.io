# 沉船磁铁捞宝 · Wreck & Reel

本地试玩 v0.10.0。每次下钩都可以直达 500 米。收线时左右拖动磁铁，从沉船里捞回宝物。

- 安装 Node.js 后，在本游戏目录运行 `npm start`。浏览器打开 `http://127.0.0.1:8954/` 即可试玩。Windows 也可运行 `node launch.mjs` 自动打开浏览器。
- 每钩的青色区会随机换位置。指针进入青色区时下钩，才能直达 500 米。抵达新深度时会保存画面左上角的个人最深纪录。
- 海里有九个区域和二十种藏品。收线时用手指、鼠标、A/D 或左右键转向，空格可下钩。接近横梁或移动潮门时会减速，优先对准青灯标出的宽口。
- 收线时按住「加速」或 Shift 可用两倍速度上升，松开即恢复正常速度。接近横梁和潮门时会自动减速。
- 磁铁初始载量 4 件，最高 14 件。磁场升级扩大吸附范围。护套每钩可挡一定次数的碰撞，触发时会亮盾、响铃并提示本钩剩余次数。
- 首次抵达 500 米时，「深渊王匣」会开箱，30,800 金币直接到账，并在船上升起金旗。动画结束后自动收线，此后可自由打捞。已经收录王匣的旧存档会保留发现纪录。
- 点音符可先听湖面曲《Still Water》，下潜时会淡入《Far Tide》，回船后切回湖面曲。音符可统一开关音乐和游戏音效。
- 普通藏品带回船上后计入航次积分并发放金币。完成委托会额外发金币并换下一单。每钩归航后可以在工坊升级，下钩时生效。灯塔开通后按分钟产出金币，离开游戏最多累计 4 小时。
- 每次归航后都可以继续下钩。下一钩会更换宝物的位置和沉船横梁开口。战报内可查看图鉴、个人纪录和财富头衔，随后继续原航次或开启新航次。
- 个人纪录按任意连续三钩的入舱积分计算。金币、升级、委托、纪录和图鉴保存在当前浏览器，旧版本的最高分会换成首次可用金币。
- 场景和藏品使用 Canvas 2D 绘制，游戏资源可以在本地加载。

操作节奏参考《Tiny Fishing》，沉船、磁铁、藏品与横梁玩法为本地原创实现。
