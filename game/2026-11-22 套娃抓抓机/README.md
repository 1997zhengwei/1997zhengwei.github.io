# 套娃抓抓机

手绘描边风格的 3D 抓娃娃机。每台机器里埋着一颗发光的**套娃扭蛋**。把它抓进出奖口：
- 扭蛋会飞到镜头前、转着裂开，蹦出一台迷你机器；
- 镜头钻进去，就到了下一层。
- 主线共 20 层，最后一层的金蛋藏着金冠和「套娃探索宗师」头衔，随后开放自由选关。

## 运行

在本目录运行 `node server.mjs`，然后打开 http://127.0.0.1:8977/ 。
- 要换端口：在 PowerShell 里先执行 `$env:PORT='8978'`，再启动。
- 不需要安装依赖，也不需要联网（three.js 在 `vendor/` 里）。
- 整个包是纯静态网页，也可以直接放到任意静态托管上。

## 玩法

- **操作**：
  - 单指拖动移动爪子，按「抓！」或空格下爪。
  - 双指拖动旋转、俯仰视角，双指捏合缩放。
  - 电脑上右键（或按住 Shift）拖动旋转，滚轮缩放，方向键或 WASD 移动爪子。
  - 左下 ⟲ ⟳ 按住可以单手转圈；👁 在正面、左侧、背面、右侧之间切换。
- **20 台主题机器**：1–5 关练基础，6–10 关组合机关，11–15 关追移动金蛋，16–20 关分别是限时冷却、双矿梯、跟帽换位、跷跷板滚蛋和手动绕杆运蛋。点主题下方的状态牌可重读线索。
- **声音**：第一次触碰或按键后开始播放原创循环音乐。「♪」控制音乐和音效。
- **首层**：金色扭蛋露在彩球上方。移到正上方时，绿圈和「抓稳！」会亮起。这一爪会稳稳夹住扭蛋。
- **爪子一次最多夹 3 个**：
  - 夹住的东西都会送进出奖口，小球、果冻块也算抓到，都有积分。
  - 越对准越容易夹牢；东西可能半路滑掉，扭蛋也会。
- **护盖**：金蛋从开场就放在托盘上，护盖从外向内一层层扣住。夹起护盖时能看到它从下面露出来。
- **次数**：
  - 前三关基础 5 次，后面基础 3 次。每件必取的护盖或钥匙另给 1 次。
  - 通关余下的机会最多带 1 次到下一关。用完可以重试当前关。
  - 点击右上角「＋」，每次挑战可花 25 积分多抓一次，也可在耗尽次数后兑换继续。
- **积分**（跨局保存）：填充物按层数给分，宝贝为层数 × 10，扭蛋为层数 × 30，金币额外给 10 积分。

## 存档

浏览器 localStorage：
- `msh-claw-20-cleared`：主线已完成的层数，完成第 20 层后保留头衔和选关。
- `msh-nest-best`：最深层数，进入新一层时立即更新。
- `msh-nest-meta`：积分余额。
- `msh-sound`：音效开关。

## 源码

- `index.html`、`base.css`、`claw.css`、`nest.css`：页面和界面。
- `themes.js`：20 台主题机器的配色、名称、线索和抓蛋规则。
- `music.js`：用 Web Audio 播放原创背景音乐。
- `nest.js`：主题模型、堆料生成、简易落体堆积、多物体抓取、套娃转场、积分商店、视角控制。
- `kit3d.js`：卡通着色加描边的 3D 小工具（合并几何、外扩描边）。
- 调试：地址加 `?dev`，然后用 `window.__nest`：
  - `dive()`：直接下一层。
  - `freeze(true)` 加 `advance(秒)`：逐帧查看。
  - `state()`：查看当前状态。
