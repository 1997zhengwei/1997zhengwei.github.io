# 宝箱别动！

手机竖屏的 3D 夜间潜行寻宝小游戏。运行 `node server.mjs` 后，用浏览器打开 [本地试玩](http://127.0.0.1:8993/)。项目内附 Three.js，可以离线运行；也可以把整个文件夹当静态网页托管。

## 玩法

- 拖动屏幕移动，**松手就钻进箱子**。手电、探头扫过来时只要不动就不会被抓。
- 带回至少 1 件宝物回到入口接应车即可撤离，带齐 3 件满载而归。
- 每夜三颗星：成功撤离 / 带回全部宝物 / 在目标时间内完成（时间显示在顶部）。

## 4 张地图 · 12 夜

| 地图 | 夜 | 新东西 |
|---|---|---|
| 黄金展厅 | 01–03 | 手电守卫；**狐疑守卫**会停下盯着可疑的箱子，这时动一下就完；第 3 夜开始出现监控探头 |
| 海盗船舱 | 04–06 | **激光栅栏**按节奏开关，亮起前会闪；躲在箱子里激光照不到 |
| 发条钟楼 | 07–09 | **巡逻犬**视野短但耳朵灵：轻推摇杆慢慢走没有脚步声，跑起来狗会转头 |
| 午夜糖果厂 | 10–12 | **钥匙卡**：金库大门锁着，先绕路找到钥匙卡 |

下一夜在上一夜通关（至少 1 星）后解锁，地图里可以随时重玩。
第 12 夜带回任意一件宝物就能通关。把糖果王冠带回接应车会解锁「传奇大盗」，获得的称号可在藏宝地图里查看。

## 商店（金币）

- **伪装箱**：快递纸箱、橡木酒桶、惊喜礼盒、盆栽、垃圾桶、黄金宝箱——松手时你变成它。
- **装备**（每项 3 级）：软底跑鞋（移速）、加厚纸板（被照到时警报变慢）、磁铁手套（吸金币范围）。
- **诱饵金币**：点右下角按钮（电脑按空格）扔出一枚，附近守卫会转头去看。成功投掷时立即扣除并保存库存。

## 操作（电脑）

方向键 / WASD 移动，按住 Shift 慢走，空格扔诱饵。

## 文件

- `rooms.js` 地图与 12 夜的关卡数据（巡逻、探头、激光、钥匙卡门）
- `logic.js` 纯逻辑（无 DOM，可在 Node 里跑测试机器人）
- `nav.js` 提供离线寻路与目标时间计算。地图改动后可用 `parTime(room)` 重新核算并更新 `rooms.js` 里的 `parSeconds`。游戏启动时直接读取这些秒数。
- `set.js` / `cast.js` / `graphics.js` 场景、角色、宝物与夜景材质
- `sound.js` 合成音效；潜行配乐只在你移动时演奏，一松手就停

记录保存在当前浏览器（`box-heist-v2`），旧版存档会自动迁移金币和藏品。

核心交互参考 RadPirates 的 [Lucky Looter](https://play.google.com/store/apps/details?id=com.radpirates.luckylooter)。本作的场景、角色模型、关卡、机关、藏品和音效均为本地原创制作。
