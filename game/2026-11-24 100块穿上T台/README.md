# 100块穿上T台 · 黑五夜 v5

v4「预算购物版」的玩法样板，按 Loopit「短平快」重做核心循环：一局 35–45 秒，10 夜逐级变难。

## 一局怎么玩
1. 开场亮出今晚的造型单：**风格 + 颜色**（例：甜美 + 粉色）、预算、优惠券。
2. 货架 3 行 × 4 件（衣服 / 鞋子 / 包包）。点商品直接进购物袋，同类再点别的就换款，点购物袋格子放回。
3. 倒计时里不断发生：
   - **闪购 5 折**：某件商品亮金框几秒，手快抢到就锁定半价；最后 10 秒闪购加速。
   - **对手抢货**：莉亚、诺拉等会拿走库存，主题款最抢手，库存 0 就售罄。
   - **优惠券**：满减（满90减30）、鞋包同买包半价、凑齐 3 件 8 折、第二贵的一件半价——到手价实时算，提示还差多少。
4. 到手价 ≤ 预算才能结账，越早结账手速分越高；时间到会自动结账（超预算或没衣服 = 失败）。
5. 小票逐行打印并盖上省钱印章。点击「上T台」后自动走秀，点击屏幕可跳过。结算时显示星级和三人排行。

手机上，到手价、预算和优惠券显示在顶栏，衣服、鞋子和包包在货架上方横排。点购物袋里的单品可将它放回货架并重新计算到手价。

## 星级与计分
- 1 星：按时结账、不超预算；2 星：总分 ≥ 60；**3 星：穿上本夜任意一套「三星搭配」**（不超预算）。
- 每夜 3 套三星搭配：「全套主题款」+ 两套「两件主题 + 一件同风格」混搭，各有名字（如「月光手包点睛」）。每夜至少一套原价就买得起；第 5–9 夜的全套主题款要抢到闪购才买得起。
- 结算页有本夜搭配图鉴：已解锁的显示单品和名字，没解锁的显示剪影和提示；选关页显示每夜「搭配 x/3」。
- 总分（满分 100：造型 60 + 省钱 25 + 手速 15）用来比三人排行、刷最高纪录——抢闪购、吃满优惠分更高。
- `node combos.mjs` 枚举每夜能三星的搭配，`node sim.mjs` 跑新手/老手机器人。

## 难度曲线
- 前 4 夜：主题款原价 + 优惠券就买得起；对手前 60% 时间不会抢光你还没拿的那类主题款（`mercy`）。主题款有金色「完美」角标。
- 第 5–10 夜：库存变少、抢货更快；全套主题款大多要抢闪购，混搭款原价可买；注意满减门槛——换便宜货可能掉出门槛反而更贵。

## 文件
- `rules.js` 纯规则（商品目录 41 件、10 夜参数、闪购/抢货市场、满减、计分），`node sim.mjs` 用新手/老手机器人跑每夜星级分布。
- `game.js` 界面流程与 3D；`fashion.js` 人物/服装/T台模型（沿用 v4）；`audio.js` 程序化音效与迪斯科 BGM（购物 / 最后 10 秒加速 / 走秀三种节奏）。
- `?dev` 暴露 `window.__rw`（advance 快进、frames 推帧、skipRunway 跳过走秀）；localStorage `runway-muted=1` 静音。

## 本地运行
在包含 `index.html` 的目录运行 `python -m http.server 9047 --bind 127.0.0.1`，打开 `http://127.0.0.1:9047/`。Three.js 和试衣间美术随源码提供，无需安装 npm 依赖。
