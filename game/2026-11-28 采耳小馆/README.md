# 采耳小馆 · 3D 耳朵 SPA（v0.4，Claude）

一只真实感的 3D 耳朵、9 种按摩道具、10 种 SPA 音源，还有一个能陪你入睡的睡眠模式。
游戏里只有"你"一个人：手里按的是自己的耳朵，耳机里听到的也是自己耳边的声音。没有计时、分数、关卡、收集，也没有客人。

## 试玩

- 双击项目根目录的 `启动采耳小馆.cmd`，或者在本目录运行 `node server.mjs`，然后打开 http://127.0.0.1:9282/
- 点「开始放松」就进入。一定要戴耳机：道具声音贴在正在按的那只耳朵一侧。
- 加 `?dev` 可以打开调试钩子 `window.__spa`（state / start / tool / flipEar / startSleep / stopSleep / scapes / view / screenOf / clearAll…）。调试时用单独的存档 key。

## 按摩道具（底部工具栏，可以左右滑）

| 道具 | 操作 | 反馈 |
|---|---|---|
| 耳勺 | 在耳甲腔、耳道里来回刮 | 皮屑翘起、"咔"地掉下，会落到纸巾上。深处那一块指在附近就会吸附上去，刮 2–3 秒"啵"地出来 |
| 可视耳勺 | 同耳勺，带 LED | 右上角小屏实时显示耳道里的画面 |
| 棉签 | 按住打圈 | 擦掉油膜和精油，棉头慢慢变黄 |
| 鹅毛 | 伸进耳道转 | 绒毛团转着压扁、撒出细粉，痒到一定程度耳朵会抖一下 |
| 精油 | 按住一滴一滴往下滴 | "滴答"落下后晕开，皮肤变得油亮 |
| 揉揉 | 按住揉；轻点一下是拍 | 按下去 Q 弹、慢慢变暖。有精油的地方声音更顺滑；拍一下是闷闷的"噗" |
| 热毛巾 | 按住敷上去 | 条纹毛巾整块盖住耳朵，冒热气，整只耳朵一起变暖 |
| 音叉 | 点一下敲响，再挪近耳朵 | 512Hz 嗡鸣，越靠近耳道越响 |
| 捂耳朵 | 按住 | 像手贴在镜头前，指缝透红光；耳边是"海浪"声，松手时"啵"一下 |

- **换只耳朵**：右上角「换只耳朵」切换左右耳。两只耳朵各自记住进度，换回来不会重置；两只耳朵挖出来的皮屑都放在同一张纸巾上。
- **视角**：双指转视角、捏合缩放；电脑上用右键拖动和滚轮。道具伸进耳道时镜头会自动推近。
- **软反馈**：左上角是放松度的表情和进度条（刚躺下 → 放松了 → 好舒服 → 睡着了）。偶尔会冒出"试试 xx～"的气泡，点一下就换到那个道具。

## SPA 音源（右上角 ♪）

- **10 种音源**：可以叠着开，每种单独调音量。
  - 👂 耳边啵啵：一左一右的"啵"
  - 🌲 森林：风吹叶子、鸟叫、远处小溪
  - 🌧️ 雨声
  - 🌊 海浪：一涨一落，左右慢慢摆
  - 🔥 篝火：噼啪声
  - 🔔 颂钵：隔一阵敲一下，余音很长
  - 💧 溪流水滴
  - 🌀 白噪音
  - 💗 心跳：每分钟 58 下
  - 🎼 轻音乐
- **默认与记忆**：第一次进来默认开"轻音乐"，之后会记住你上次开了哪些、音量多大。
- **道具声音开关**：在音源面板底部，只关道具声，不影响音源。
- **实现**：全部用 WebAudio 现场合成，没有音频文件。长时间播放时复用声像节点，不会越积越多。

## 🌙 睡眠模式（右上角 ☾）

睡眠模式是背景音和采耳声的有机组合：背景音一直铺着，采耳声随机穿插。

- **组合**：可选 6 套。开始时只开这套的背景音，用临时音量，不改你自己存的音量；退出后恢复你原来开的音源。

  | 组合 | 背景音 | 会出现的道具 |
  |---|---|---|
  | 🌧️ 雨夜采耳 | 雨声、心跳、轻音乐 | 耳勺、棉签、可视耳勺、揉揉、热毛巾 |
  | 🌲 森林按摩 | 森林、溪流 | 揉揉、热毛巾、棉签、精油、音叉 |
  | 🌊 海边 SPA | 海浪、颂钵 | 捂耳朵、精油、揉揉、热毛巾、音叉 |
  | 🔥 炉边掏耳 | 篝火、心跳、白噪音 | 耳勺、可视耳勺、棉签、揉揉 |
  | 👂 只听啵啵 | 耳边啵啵、白噪音 | 棉签、揉揉、捂耳朵 |
  | ✨ 我的组合 | 你在 ♪ 里开着的音源 | 除鹅毛外的全部道具 |

- **穿插采耳声**（默认开）：
  - 道具从组合里随机挑一段（10–26 秒），动作放慢到约一半。
  - 段与段之间留 5–12 秒只有背景音。滴完精油会接着揉开。
  - 大约每 7 段换一次耳朵。
- **声音更柔**：睡眠时道具声会削掉 3.8kHz 以上的刺耳高频，音量降到约一半；鹅毛平时也调小了。
- **定时**：可选 15 分钟、30 分钟、1 小时或不定时。最后 90 秒声音淡出，然后屏幕全黑，显示"晚安"，点一下回来。
- **屏幕**：越来越暗，界面 5 秒后自动隐藏。自己碰屏幕时，采耳声会让开 12 秒。点屏幕顶部的小条可以退出。

## 技术要点

- **耳朵建模**：`src/ear-sdf.js` 用 2D 烘焙耳廓加 3D 距离场，再用 surface nets 出网格。网格在 Web Worker 里生成，桌面约 1–2 秒。点选用距离场做 sphere tracing。
- **皮肤着色器**（`src/scene.js`）：薄处透光、油膜、精油、泛红、按压形变、抖动。
- **道具声音**（`src/asmr-audio.js`）：
  - 贴耳双声道：远耳一侧延迟 0.68ms、低通、音量约 1/3。
  - 进耳道、捂耳朵、敷毛巾时声音会变闷。
  - 道具声音单独一条总线，睡眠时走柔和通路（低通 + 降音量），最后还有一个睡眠淡出节点。
- **音源**：`src/soundscapes.js`。
- **依赖**：three.js r170（unpkg 加载）。网页字体来自 Google Fonts。

## 已验证 / 未验证

- **已验证**：无头 Chrome（430×932 竖屏、静音、临时配置）跑完了以下流程，无报错，帧率约 95–100：
  - 9 种道具、换耳不重置、挖深处大块
  - 音源开关和音量
  - 睡眠组合：背景音常开，道具随机穿插并留空；退出后恢复自己的音源；睡眠时鹅毛声的 RMS 从 0.07 降到 0.027
  - 碰屏幕让位、定时淡出到"晚安"
  - 触屏刮擦、双指缩放
- **未验证**：
  - 所有声音的实际听感：测试都是静音跑的，需要戴耳机试听，尤其是新加的 10 种音源。
  - 真机触感和性能。
  - 手机锁屏后浏览器可能暂停声音，这是浏览器的限制；睡眠时建议不锁屏，屏幕会自己变暗。
