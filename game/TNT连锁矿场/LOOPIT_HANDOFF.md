# TNT Mine Rush · 本地源码交接基线

当前基线：v0.6.1，用户已授权上传 GitHub。目标为 `1997zhengwei/1997zhengwei.github.io` 默认 `main` 分支的 `game/TNT连锁矿场/`。已接入 Loopit V2 草稿并实际试玩，未发布/送审。当前产物、Power、验收与平台差异见 [SYNC_STATUS.md](SYNC_STATUS.md)。

## 运行

静态 HTML / 原生 ES modules / 本地 Three.js。无安装、无构建、无远程 CDN。用 HTTP 服务打开 `index.html`；本地可执行 `python serve.py --open`，默认端口 8877。完整复制本目录即可独立运行；`file://` 不适用于 ES modules。

## 必须保留

- 原创明亮卡通矿洞、三张教学图、24 层随机探险、手机纵向镜头和拖动查看。
- 点可达边界采矿；泥土煤 1 次、石头金 2 次、钻石 3 次。TNT 为 1 次引爆 3×3，并按实际范围连锁，基岩不可破坏。
- 三张教学预算 14/20/28；随机开局至少 52，保守路线成本 +14 校验预算。8 米和16 米各 +6，每局各一次，最后一击越过补给时仍发放。
- 补给到账后显示约 3.8 秒金色通知，显示具体深度、`+6 PICKAXE HITS`、已经加到镐子；通知不阻挡触控、不同矿块悬停文案不会覆盖它。音效和减少动态效果设置生效。
- 自选 Route 下一格提示、随机局免费修镐续玩、同种子重玩、新随机矿洞、真实结算、浏览器续存。
- 旧存档安全迁移：已开挖 80 点局保留剩余耐久；未开挖旧局、新局采用新预算；补给不可通过刷新反复领。

## 资源与验证

`assets/mine-atlas-v04.png` 为矿块图集；`assets/miner-v06.png` 为正在使用的大脸卡通矿工，`miner-v04.png` 作为生成参考来源保留。资源由内置 image_gen 生成，完整提示词见对应 JSON。`pixel-miner.js` 仅为加载失败回退。背景、矿石反馈与短音效由代码生成；Three.js 许可证在 `vendor/LICENSE`。

规则测试：`npm test`（25 项）。浏览器补给证据和当前验收范围见 `QA.md`；模拟路线审计不是人类通关率。按实际 Loopit 宿主尺寸重新验收触控对齐、通知可读、声音开关、结算/重开、状态恢复后才能标记平台接入完成。

接入时应读取完整源码与本地素材，仅做平台所需的资源/构建/视口适配；不从标题重新生成另一套地图和规则。
