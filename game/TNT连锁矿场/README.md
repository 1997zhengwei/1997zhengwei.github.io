# TNT 连锁矿场 / TNT Mine Rush

可独立运行的游戏源码 **0.6.1 · 清楚的深度补给通知**。已接入 Loopit V2 草稿并实际试玩，尚未发布。平台版另有事件震动 Power；本地运行基线保持不变。详见 [同步与验收记录](SYNC_STATUS.md)。

## 启动

在本机双击 `开始试玩.cmd`，或在本目录运行：

```sh
python serve.py --open
```

试玩入口为 http://127.0.0.1:8877/ 。已有服务时会复用同一游戏服务。Python 3、支持 WebGL 的浏览器即可运行；不需要 npm install、不依赖远程 CDN 或字体。

## 怎么玩

- 点有浅金轮廓的方块，每点一次消耗 1 点镐子耐久。
- 泥土、煤：1 次；石头、金矿：2 次；钻石：3 次。小点表示硬度，裂纹表示已敲击。
- TNT：1 次，引爆周围 3×3 范围，免费收集其中矿石，并连锁引爆范围内其他 TNT。基岩不可破坏。
- 挖开的连通空间会扩大可开采边界；隔着岩壁不能直接点远处矿石。
- 拖动矿洞或使用上下箭头观察地形；“Dig site”回到当前开采深度。
- 三张教学图依次学习连锁、节省耐久和深层选路。随机探险为 24 层、开局至少 52 点耐久，首次到达 8 米、16 米各补 6 点，目标是收集底部宝箱；每张图先校验到达路线并预留探索余量。每次新探险使用不同布局。
- 随机矿洞的目标旁有 `Route`：按需显示下一块安全路线方块及保守剩余成本，不扣耐久、不自动挖掘。
- 随机矿洞耐久耗尽时可选择 `Free repair · continue`，免费保留当前地图、已挖方块、收获和分数继续。本次修镐覆盖剩余保守路线并额外留 12 次敲击，至少补充 24 次；可以再次使用。
- 旧 42 点局只补预算差额；尚未开挖的旧 80 点局采用新预算，已开挖的旧 80 点局保留剩余耐久。存档迁移和深度奖励均不会反复补发；新局、重玩采用新版规则。
- 结算可以重玩同一矿洞或换一个随机种子。右下角 ↗ 可提前结束本局，结算已采到的宝藏。
- 声音、减少动态效果、教学星级、探险最高分及未完成局面均保存在当前浏览器。测试入口 `?qa=1` 使用独立存档。
- 键盘：聚焦矿洞后按方向键选择，Enter / Space 开采。帮助窗口支持 Tab 焦点循环与 Esc 返回。

## 画面修订

0.6.1 首次到达 8 米和 16 米时，显示独立金色补给通知：深度检查点、`+6 PICKAXE HITS`、已加入镐子耐久。通知显示约 3.8 秒，不拦截点击，不被矿块说明覆盖；同时闪亮耐久条，并在声音开启时播放短提示音。

0.6 回到精致卡通矿工，使用内置 image_gen 重画大脸、清晰头灯和简洁的镐子轮廓，再按透明边界裁紧以适配手机实际尺寸。人物文件为 `assets/miner-v06.png`，实际提示词见 `assets/generation-v06.json`。随机预算改为 52 起步与两次深度补给，详见 `BALANCE_V06.md`。下方为历史修订记录。

0.5 将人物改为 40×48 整数网格绘制的方块像素角色，使用最近邻采样，无小尺寸绘画纹理；放大脸部、头灯、衣服与镐子的轮廓。原 0.4 矿块图集、清新配色和音效保留。教程规则与地图不改；本版按用户反馈修改了随机耐久、路线提示、免费修镐及旧存档迁移，详见 `BALANCE_V05.md`。

0.4 版依据用户补充的参考截图，重做整套游戏美术。新增内置 image_gen 生成的原创透明矿块图集和矿工角色，并实际接入场景：青绿、暖金、冰蓝洞窟，白底矿石、黑色煤块、柠檬黄金块、青蓝钻石、明红 TNT、金色宝箱。矿块保留明确描边及白色高光，采用不受动态灯光压暗的正面材质；去掉全局褐色压暗曲线，局部泛光只强调有色亮点。HUD 改为清新的青绿和亮黄，目标提示上移以避开角色脸部。

固定教学图分别展示三种矿区配色，随机矿洞根据既有种子选择配色，仅影响外观。核心规则文件、输入/存档逻辑及音频未改。资源说明和完整生成提示词见 `ART_DIRECTION_V04.md`、`assets/generation-v04.json`。

0.3 版按“玩法不用改”的要求，只升级渲染和 HUD：凸出岩面的真实立体矿石、金块和煤块；更自然的岩块轮廓与阴影切面；远景水晶、光束、浮尘、晶体反光；轻量多通道泛光；TNT 光线冲击与收集反馈；矿工装备细节；带切角选框、硬度点和金属质感的 HUD。镜头投影与点击拾取模型保持原有参数。减少动态效果模式静止浮尘/晶体闪光，并减少爆炸亮度和射线。

`core.mjs`、`app.js`、`audio.js` 与 0.2 版逐字节一致，地图、随机生成、耐久、连锁、计分、输入逻辑、存档键及音频均未调整。

根据用户提供的 Pocket Mine 参考截图，0.2 版将浅色面板与棋盘构图改为满屏纵向洞窟：不规则岩石切面与空腔、矿洞背景、梯子、木梁、藤蔓、火把光晕、切面矿石、灯帽矿工，以及爆炸冲击波、碎块和矿石收集飞行动画。教学图 2 为暖色矿区，其余为青蓝洞窟。HUD 覆盖在游戏场景上方。

0.2 / 0.3 的素材由本项目代码绘制/建模；0.4 新增内置 image_gen 生成的原创图集及角色，背景和反馈继续由代码绘制。没有把参考游戏截图或原作人物文件作为运行素材。玩法借鉴 Pocket Mine 的采矿与连锁机制，保留 Minecraft 方块题材；不是官方 Minecraft 或 Pocket Mine 产品。

## 文件

- `core.mjs`：地图、连通可挖边界、硬度/耐久、连锁、奖励、目标、结算。
- `scene.js`：Three.js 场景、原创程序纹理、输入拾取、镜头与反馈。
- `visuals.js`：立体矿石、环境细节、浮尘与轻量泛光管线。
- `art.js`、`assets/`：新卡通图集与矿工精灵、素材载入与回退、生成记录。
- `pixel-miner.js`：0.5 版原生像素角色，0.6 仅作为图片加载失败时的回退。
- `app.js`：界面、流程、存档、可访问操作。
- `audio.js`：原创合成短音效，静音和生命周期。
- `style.css`、`arcade.css`、`polish.css`、`fresh.css`：基础布局及历次 HUD 风格。
- `vendor/`：本地 Three.js 依赖及 MIT 许可证。
- `tests/`、`qa/`：规则测试、操作路线和真实浏览器截图。
