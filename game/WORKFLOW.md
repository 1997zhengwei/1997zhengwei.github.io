# 游戏长期存放约定

用户于 2026-11-10 明确要求：已完成游戏、矿车归途及以后的新游戏，统一放到仓库默认 main 分支根目录的 game 下。

1. 固定位置：默认 `main` 分支的 `game/YYYY-MM-DD 中文游戏名/`。日期与作品名之间用一个空格。
2. 每款作品沿用首次收录日期和目录名，后续版本通过 Git 提交追踪。
3. 本地实现与试玩 → 用户认可并授权上传 → 同步本目录 → 用固定提交交给 Loopit 接入 → 实际试玩并记录平台结果。
4. 每款游戏保持可独立运行：入口、src、必要素材与许可证、README、验收和平台交接说明。缓存、凭据、PID、临时日志与其他项目文件不上传。
5. 更新 [游戏作品总目录](./README.md)。新作品在对应年份和月份添加一行，以 `YYYY-MM-DD 游戏名` 开头，链接到该作品带日期的目录。日期采用北京时间，以可核实的首次 GitHub 记录为准。后续改版沿用首次记录日期，各版及 Loopit 状态写入作品自己的交接记录。
6. 交接源码使用固定提交链接。历史路径见 [迁移记录](./MIGRATION.md)。
7. 个人主页、学术代码与部署配置不随游戏整理修改。
