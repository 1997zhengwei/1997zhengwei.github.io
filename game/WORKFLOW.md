# 游戏长期存放约定

用户于 2026-11-10 明确要求：已完成游戏、矿车归途及以后的新游戏，统一放到仓库默认 main 分支根目录的 game 下。

1. 固定位置：`game/<中文游戏名>/`，不再把新的游戏交付存到旧专用分支的 games 下。
2. 一个游戏一个稳定中文目录，版本用 Git 提交追踪；不重复建立 final、v2、latest 等平行成品目录。
3. 本地实现与试玩 → 用户认可并授权上传 → 同步本目录 → 用固定提交交给 Loopit 接入 → 实际试玩并记录平台结果。
4. 每款游戏保持可独立运行：入口、src、必要素材与许可证、README、验收和平台交接说明。缓存、凭据、PID、临时日志与其他项目文件不上传。
5. 更新 game/README.md 的中文索引。明确区分本地通过、源码已同步、Loopit 草稿、已发布。
6. 旧路径和固定提交保留兼容；已有代码、素材或外部引用不因目录整理而被删除。
7. 个人主页、学术代码与部署配置不随游戏整理修改。
8. 本次对矿车归途的授权为 GitHub 同步和 Loopit 初稿；不包含发布展厅或送审。未来每次操作仍按用户当次授权范围执行。
