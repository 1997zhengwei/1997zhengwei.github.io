# 奶油派对 · Frost & Feast

本地 3D 裱花游戏，v0.3.0。参考 **Icing On The Cake** 的转台裱花、抹平手感，以及蓝字、黄框、白灰背景的简洁构图。模型、奶油表面、工具、装饰与界面均为本项目制作。

## 启动

在游戏目录执行：

```sh
node server.mjs 8941
```

浏览器打开 <http://127.0.0.1:8941/>。需要支持 WebGL 的现代浏览器。运行依赖已放在 `vendor/`，无需安装 npm 包或访问 CDN。

## 操作

1. 参考右上角的小蛋糕，选择奶油颜色。
2. 在画面中按住鼠标或手指，蛋糕自动旋转；上下移动调整裱花高度。
3. 「顶部」可在顶面挤出奶油圈。每份蛋糕已有一层顶面底霜。
4. 点击「开始抹平」，按住并上下移动刮刀，使凸起的奶油逐渐平整。
5. 选择点缀并轻点顶面。按住可随着转台沿圈摆放；撤销可删除最后一个。
6. 点击「完成作品」，查看实际成品照片、配色、覆盖与平滑度。可重做、继续下一份，或回到首页看作品集。

没有倒计时，也不会自动替玩家完成。裱花和抹平可返回上一步修改。

## 内容

- 8 份手工配色的甜点订单，包含莓果蛋糕、感恩节南瓜派、枫糖与丰收主题。
- 完成后继续生成新的配色订单；另有 10 色自由创作模式。
- 6 种立体点缀：奶油花、蔓越莓、枫叶糖、小南瓜、碧根果、糖珠。
- 保存最近 9 份实际成品照片、订单星级与最佳分数。
- 挤奶油、刮刀与完成提示音，设置里可关闭。
- 金币目前用于记录制作成果，尚未加入消费商店。

## v0.2 视觉重制

- 奶油厚度由实际笔触沉积，代替固定周期的细环纹；抹平会消去相应位置的凸起。
- 奶油增加细颗粒与刮痕材质，强化紫、蓝、莓红的色彩分离。
- 重做褶皱裱花袋、连接件与金属花嘴，放大金属刮刀与蓝色防滑手柄。
- 重做奶油色转台、深色支柱、接触阴影及反射环境。
- 调整黄框、蓝色标题、星级、目标图和触控色块的比例。
- 针对 320×580 与 390×844 检查布局，并让小屏镜头保留完整的转台。

## v0.3 质感提升（Claude，2026-11-18）

- **奶油条**：沉积改为圆截面，新挤的一圈会轻压旧的一圈，圈与圈之间留出凹槽；凹槽按几何自动压暗（腔体阴影），一圈圈奶油条清晰可见。
- **奶油材质**：去掉会显得像毛巾/绒布的灰色颗粒贴图，改为沿转向的柔和褶皱 + 细裱花纹；缎面光泽、薄黄油层高光；彩色奶油的暗部保持饱和（近似次表面散射），白奶油不受影响。
- **抹平**：刮过的地方褶皱减弱成细刮痕，色带交界被刮刀带开、互相晕染（只影响显示，评分仍按真实颜色）。
- **奶油边缘**：奶油改为不透明实体；挤得少的地方，奶油边缘圆滑地沉进蛋糕胚，与蛋糕胚形成干净的交线。修复了原来边缘半透明、透出蛋糕胚，以及两层贴得太近互相闪烁、像错位交织的问题。覆盖率在显示前先柔化，边缘不再出现锯齿；边缘颜色取相邻奶油的颜色，不会发黑。
- **落点修正**：修复原版的旋转方向符号错误——之前奶油不是落在裱花嘴下，而是落在一个以两倍速度绕蛋糕跑的位置（常在背面）；现在在任何转角都准确落在嘴下，抹平也准确作用在刮刀处。
- **刮刀贴合**：刮刀每帧按刀面覆盖区域的奶油最外层定位，贴在奶油表面上，不再插进奶油里；抹蛋糕底部时刀身最低停在转台上沿，不会穿进转台。挤最底一圈时，裱花袋尾部自动上翘避开转台，嘴尖仍对准落点。
- **顶部收边**：侧面奶油在顶边卷成圆肩并收进顶层下方，去掉了原来露出的黄色缝线；顶面中心不再出现放射状细纹。
- **布光**：用 PMREM 预滤波的小摄影棚做环境反射（大柔光箱、竖条灯、背后轮廓灯），配合主光，蛋糕侧面有竖向高光。
- **工具**：刮刀改为拉丝不锈钢、刀面微弧并侧转接光；裱花嘴挤奶油时伸出一小段同色奶油。
- **点缀**：奶油花与蔓越莓改用奶油/果实材质。
- **界面**：所选颜色名并入右侧状态文字（「香芋奶油 · 覆盖 99%」），修复四色订单时浮动颜色名压住覆盖率的问题。
- **按钮与界面（糖果质感）**：主按钮改为上亮下暗的绿色胶囊，带厚度阴影、顶部高光和按下回弹，箭头/对勾放进圆形徽章；奶油色块改成带高光的糖果块，选中时抬起、加白圈和蓝色对勾角标；侧面/顶部为胶囊分段开关；顶栏撤销/设置改为半透明圆形 SVG 图标；星星改为金色渐变 SVG；目标卡、点缀卡、首页「订单簿 / 自由创作 / 我的作品」、金币、结算卡、弹窗统一圆角与阴影。
- **少女心动效**（`src/fx.mjs` 粒子层 + CSS 动画）：挤奶油时嘴尖冒出小爱心和闪光；抹平时刀边闪烁星光；点缀弹跳落下并爆出一圈爱心；覆盖率/平滑度/点缀数到节点时跳出夸奖字（「哇~ 好可爱！」「甜度满分！」「完美裹满啦！」「好丝滑~」「像镜子一样亮！」「仙女蛋糕诞生！」）；拿星时星星盖章并迸出金色闪光；结算时落下爱心/星星/彩带，卡片弹出，分数滚动计数，星星逐个盖章，标题彩虹流光，「你的作品」角上跳动小爱心；首页飘粉色泡泡与小爱心，蛋糕轻轻浮动，标题摇摆；色块果冻弹、主按钮呼吸扫光、目标卡轻浮。配套「啵」「叮铃」「叮」音效。系统开启「减少动态效果」时自动减量。

## 验证与构建

```sh
npm test
npm run build
```

构建输出在 `dist/`，可以用普通静态网站服务运行。测试覆盖实际沉积、环绕接缝、抹平不凭空上色、撤销、正确配色、空白与错误配色评分。浏览器实操记录见 `QA.md`。

代码结构：`frost.mjs` 是奶油数据与评分；`look.mjs` 是表面、工具与材质；`render.mjs` 负责相机和交互；`app.mjs` 负责流程、界面和存档。
