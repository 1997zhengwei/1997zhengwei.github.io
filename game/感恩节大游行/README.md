# 感恩节大游行 · 气球领队

本地 v0.3.1，中文版。真 3D（Three.js r186）感恩节游行气球动作游戏：你是巨型气球的领队，带着拉绳队穿过城市街道，左右躲障碍、压低气球钻横幅、接路边观众入队。

参考：《Crowd City》的“队伍越走越大、人数可见”，以及《Totally Reliable Delivery Service》式的摇晃物理喜感。只借鉴手感方向，玩法规则、关卡、模型、代码都是原创。

## 打开

双击工作区根目录「启动感恩节大游行.cmd」，或本目录「打开游戏.cmd」。默认地址 **http://localhost:8911/**（端口被占用会依次尝试 8912–8920）。

也可以 `python -B serve.py --port 8911`。不需要 npm install、不联网；请通过本地 HTTP 打开。

- **三个超能力**（右侧按钮，数字是剩余次数，开局各 1 次）：
  - 🛡️ 无敌护盾（5 秒）：金色护罩，横幅、横杆、路障全部撞飞，每撞飞一个 +15 分。
  - 🧲 星星磁铁（7 秒）：前方附近的星星自动飞进气球。

- **得分、金币、换装**：每局按星星、距离、剩余气量、人数、撞飞数和通关星级算分，得分 ÷10 + 星级奖励 = 金币。首页「装扮商店」可买气球帽子（派对尖帽、感恩节礼帽、大厨高帽、黄金皇冠）、眼镜（墨镜、爱心眼镜）、围脖（格纹围巾、红色领结）和拉绳队队服（蓝色水手、南瓜橙、森林精灵、金色冠军）。
- **段位**：按最高分从「游行新手」升到「传奇领队」，结算页显示离下一段位还差多少分，破纪录有提示。没有接入线上排行榜（没有服务端，不伪造他人成绩）。

## 怎么玩

- **手机**：一只手在屏幕上左右拖动，带拉绳队换位置；另一只手按住右下「按住拉低」把气球拉低。
- **电脑**：← → 或 A D 移动；空格 / ↓ / S 按住拉低；1 无敌、2 磁铁、3 号召。Esc 暂停。
- 气球默认飘在高空，按住拉低才会下降；人越多拉得越快、越不怕风。

| 遇到 | 怎么过 |
| --- | --- |
| 🎌 横幅 / 🌉 大桥 | 按住拉低，从下面钻过去 |
| 🚦 红绿灯横杆 | 松手让气球升高，或带队伍走到另一边 |
| 🪧 高处招牌 | 不要贴着那一侧，或者拉低 |
| 🍁 行道树 | 气球保持在路中间 |
| 🚧 路障 / 🎃 推车 | 拖动让拉绳队绕开；撞上会摔倒 2–3 人 |
| 🙋 路边观众（绿圈） | 队伍走过就加入 +3/+4 人 |
| 💨 打气站（蓝圈） | 队伍走过给气球补 30 气 |
| 🌬️ 强风 | 屏幕会提示方向，往反方向拉住 |
| ⭐ 星星 | 让气球碰到就得分；常放在“正确通过路线”上 |

气球撞到东西会漏气（并短暂无敌）；气漏光或拉绳队全部摔倒就失败。每种障碍第一次出现时，顶部会弹出一句提示。

### 星级

通关 ★；剩余气量 ≥ 50% ★★；再加上收集 ≥ 60% 的星星 ★★★。

| --- | --- | --- | --- |

| 气球 | 特点 | 解锁 |
| --- | --- | --- |
| 火鸡 | 均衡，100 气 | 默认 |

## 存档

浏览器 localStorage，键 `tg-parade-v1`：各路线最高星级、无尽最远距离、最高分、金币、已购与穿戴的装扮、声音开关、上次选择。

## 开发

- `npm test`：物理、碰撞、拾取与机器人通关测试（Node 内置 test runner，无依赖，约 5 秒）。
- `node tools/bot.mjs`：打印每条路线 × 每种气球的机器人成绩。
- `npm run build`：检查模块语法与相对导入，生成自包含 `dist/`。

结构：`src/sim.mjs`（纯逻辑：路线生成、气球物理、碰撞，可在 Node 测试）、`src/models.mjs`（街区、障碍、气球、队员的程序化 3D 模型）、`src/app.mjs`（渲染、输入、HUD、流程）、`src/audio.mjs`（Web Audio 合成音效与游行鼓点）。
