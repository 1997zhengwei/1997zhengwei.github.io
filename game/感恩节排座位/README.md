# 开饭啦！感恩节排座位 · Thanksgiving Seating Chaos

本地 v0.2.0，中文版。真 3D（Three.js r186）感恩节排座位解谜：把一大家子亲戚安排上餐桌，再看这顿饭是温馨团圆，还是一场食物大战。

参考：《Totally Accurate Battle Simulator》的“先布置、再看模拟”结构，加逻辑排座谜题。只借鉴结构，人物、规则、场景、代码全部原创。

## 打开

双击工作区根目录「启动感恩节排座位.cmd」，或本目录「打开游戏.cmd」。默认地址 **http://localhost:8901/**（端口被占用会依次尝试 8902–8910）。

也可以 `python -B serve.py --port 8901`。不需要 npm install、不联网；请通过本地 HTTP 打开，不能直接双击 index.html。

## v0.2 改动（2026-11-14，按用户反馈“文字太多、不好上手”）

- **看图不读字**：亲戚卡片、选中面板、关卡提示都换成头像+图标：❤️ 想挨着、⚡ 会吵架、🚫 不要、🔥 暖炉、🐶 狗狗、👑 主位、菜品图标。
- **拖上去立刻看反应**：拖动卡片经过座位时先“试坐”，全桌表情、❤️ 粉色连线、⚡ 闪电连线马上变化；松手才确定。桌上的人也能直接拖去别的座位，拖到桌外就是起身。
- **头顶直接画原因**：谁不开心，头顶就冒出让 TA 不爽的东西（讨厌的人头像、暖炉、狗、菜）；开饭会动手的人头上有闪烁的 💣。
- **第一关手势引导**：手指拖着奶奶头像从卡片滑到座位，示范一次。
- **晚宴更刺激**：寒暄环节加快；“🔥 食物大战！”大横幅、第一发慢动作特写、镜头追打、震屏、满屏糊食物、💥 连击计数；团圆成功有举杯和彩纸。

## 怎么玩

1. 点底部亲戚卡片（或直接把卡片拖到餐桌上）→ 点发光的空座位让 TA 坐下。
2. 头顶表情实时显示心情：😍 超开心 / 😄 开心 / 🙂 还行 / 😒 不太爽 / 😡 要发火；👊 表示开饭后会动手。桌上 ❤️ 是互相喜欢的邻座，⚡ 是会吵起来的邻座。
3. 点已入座的人可以看 TA 的每条喜好是否满足，再点另一个座位就能换位；「起身回到候选」把 TA 放回托盘。
4. 全员入座后按「开饭！」，观看三维晚宴：环境反应 → 碰杯寒暄 → 拌嘴 → 劝架/扔食物。可以快进或跳到结果。
5. 结算页逐人给出一句话，解释 TA 为什么开心或生气。

### 规则

- 邻座 = 同侧左右 + 正对面 + 桌头与两侧第一位。
- 基础心情 1；每满足一条喜欢 +1，每触发一条讨厌 −2。
- 喜好类型：想/不想挨着某人、爱吃/不想靠近某道菜（坐在那一排）、暖炉（右上）、狗狗豆豆（左下）、桌头主位。
- 心情 ≤ −1 且旁边有讨厌的人 → 开饭后会扔食物；大伯急脾气，心情 ≤ 0 就动手。
- 被砸中心情 −2，可能还手（每人最多扔两次）。小弟手滑，总会砸到目标旁边的人。
- 奶奶心情好时会劝住身边要动手的人一次；她被砸后就不劝了。

## 存档

浏览器 localStorage，键 `tg-seating-v1`，只存各关最高星级和声音开关。

## 开发

- `npm test`：规则单元测试（Node 内置 test runner，无依赖）。
- `node tools/analyze.mjs [关卡号]`：穷举星级分布（第 6、7 关约 2–3 分钟）。
- `npm run build`：检查模块语法与相对导入，生成自包含 `dist/`。

结构：`src/data.mjs`（座位/菜品/亲戚/关卡）、`src/rules.mjs`（纯规则与晚宴模拟，可在 Node 测试）、`src/models.mjs`（程序化 3D 模型）、`src/app.mjs`（渲染、交互、播放、界面）、`src/audio.mjs`（Web Audio 合成音效）。
