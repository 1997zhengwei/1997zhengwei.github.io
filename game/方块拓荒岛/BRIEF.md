Grass home → woodland / workbench → optional wheat pasture / waterfall grove → bridge → iron quarry / furnace → iron tools → ridge → ancient ruins / villager / optional treasure → portal restored. Regenerating resources, persistent partial construction payments and no finite resource softlocks. Stone tool tier unlocks iron ore; iron tools unlock obsidian. Optional branches provide alternate emerald access.
