## Import the real game

This is a complete, playable, original Three.js browser game. Copy the supplied source files and dependencies. Do not rebuild a simplified game from the title or screenshots. The source is the rules and visual baseline. Do not embed GitHub Pages or localhost in an iframe.

- Entry: `index.html`; native ES modules, no npm installation or build step needed locally. Static HTTP hosting is sufficient.
- Runtime: `app.js`, `scene.js`, `models.js`, `audio.js`, `style.css`, `core.mjs`, `campaign.mjs`, `combat.mjs`, `golems.mjs`, `markers.mjs`.
- Vendor: **both** `vendor/three.module.js` and `vendor/three.core.js`, with `vendor/LICENSE`. All imports are relative. If the host must bundle, use its normal build pipeline without changing the rules.
- Original voxel models, pixel textures and synthesized Web Audio are generated by code. No external image, font or music service is required. Retain the Minecraft inspired art and English player text.

- `serve.py` and `开始试玩.cmd` are local launch helpers, not production server requirements.

## Preserve these features

1. Full 20-night campaign, 775 authored enemies, 23 sites, five building levels, four directions. Regions/upgrades unlock on days 6/11/16, south raids start night 11; sieges at 5/10/15/20. Do not shorten the campaign.
2. Day: select a site, build/upgrade/repair/salvage with the real emerald budget, preview the next raid, explicitly start night. Farms pay only after a successful night; repair the bell for 3 emeralds / 45 HP.
3. Night: touch-drag or tap ground to move Steve, auto-shoot nearby targets, Volley at up to six targets with 10s cooldown. Keyboard is an optional aid. Steve returns after five seconds; bell HP zero is defeat. Keep retry-from-dawn, victory and restart.
4. Real 3D voxel scene, bright green village, wooden houses, roads, solid buildings, district close-ups, whole-map navigation and night-follow camera. Preserve readable phone controls and marker hit areas.
5. **v0.3.0 cover fix:** melee cannot cross an intact barricade; main watchtowers stand behind cover. Houses/buildings intercept low arrows using the same 3D trajectory as rendering. Tower lob arrows may clear walls; destroyed cover ceases blocking immediately. Spiders climb walls; creeper blasts and ravager shockwaves intentionally splash nearby structures. The exposed southern Ridge Watch has an explanation.
6. **Persistent golems:** independent friendly HP bars, low-health color, standing/total counter, fall/fade effect and location-specific death toast. HP and deaths persist across nights; there is no free respawn. Yard repair does not heal troops.
7. **SQUAD panel:** per-unit repair/recruit and restore-all, actual HP and exact price before payment. Living repair = ceil(missingHP/90) per unit. Yard levels 1–5 recruit prices 3/3/4/5/6; HP 180/220/255/295/340; slots 1/1/2/2/3. Upgrade preserves injury fraction and fallen slots, adding only newly unlocked slots. Ruined yard must be repaired first. No spending at night.
8. Physical repair prices and salvage deficit rules in source: healthy buildings refund the investment; damage/missing troops reduce the refund, so sell-and-rebuild cannot bypass upkeep.
9. Auto-save, pause/help/background pause, sound toggle and reduced-motion preference. Keep the v2-to-v3 migration and one-time rules notice; do not silently reset an existing campaign.
