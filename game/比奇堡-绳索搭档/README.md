# 比奇堡·绳索搭档

用户于 2026-11-04 验收的本地版本：海绵宝宝和派大星穿运动队服，用有弹性的绳子交替跨平台。小跳由玩家自己控制，落地只保留轻弹缓冲。

## 试玩与操作

在本目录执行 `python -m http.server 8772 --bind 127.0.0.1`，打开 <http://127.0.0.1:8772/>。无需 npm、联网素材或 API Key。请通过 HTTP 打开，不能直接双击 HTML。

- 左/右按钮、左右方向键或 A/D：让箭头所指的搭档向相应方向小跳，按住可连续蹦。换手后控制新搭档；不会自动替玩家向前走。
- 主按钮或空格：绿圈亮起时换手。轻松模式按住可连续接力；挑战模式提前换手会失去支撑。
- 绳长滑块：调整下一次换手后使用的绳长。
- 绳子松时会下垂，拉长产生张力，回弹会改变人物的实际速度和飞行。小跳有短暂的站位稳定辅助，避免普通一步被甩得过大。
- 三段主线、28 次接力、蟹黄堡收集、移动水母、检查点与重试。通关后可继续无尽路线。
- 轻松模式每个检查点提供一次泡泡护盾。暂停/失焦/切页会停止模拟并清除按住输入。音效默认关闭，♪ 开启原创合成提示音；没有电视剧原声或 BGM。

## 源码与验证

| 文件 | 用途 |
| --- | --- |
| `rules.mjs` | 状态、输入规则、路线、收集、检查点、胜负和重试 |
| `physics.mjs` | 弹簧张力、阻尼、重力、伸长上限、固定子步和起摆辅助 |
| `rope.mjs` | 轻量 Verlet 绳链，表现松垂、惯性和回弹 |
| `landing.mjs` | 落地缓冲与手动小跳姿态 |
| `scene.mjs` | 三维场景、镜头和反馈 |
| `characters.mjs` / `sportswear.mjs` | 人物、腿部节点和运动装 |
| `app.mjs` / `index.html` / `style.css` | 中文界面、触控、键盘、暂停与声音 |
