# 水上飞跃大赛 · SPLASH RIVALS

源码交付版本 v0.8.0，2026-11-09。真实Three.js三维水滑道竞速，手机竖屏优先，桌面也能玩。三张地图分别为回旋、直道发卡、双层交叉构型，保留辅助滑翔和4秒预览。本轮玩家冲刺延长到6秒，对手保持3秒。GitHub中文目录为`games/水上飞跃大赛/`；尚未接入Loopit。

## 启动

双击本目录的`启动试玩.cmd`，或运行`python serve.py --open`。

试玩：<http://127.0.0.1:8794/?v=0.8.0>。Python仅提供本地静态文件服务，游戏运行不请求第三方资源。

## 新版变化

- 跟手转向：拖动画面直接指定横向位置；方向按钮、A/D和方向键用于持续转向。松手快速制动横移，减少滑过头。选手间碰撞的横向推力降低。
- 普通飞跃也先选择经过检测的安全赛段，采用连续弧线飞行。空中点左/中/右选择落点，或轻拖/方向键微调；范围缩到中心两侧各1.8米，松手吸附安全位置，最后约0.3秒自动对齐。普通飞跃至少约1.8秒，增加反应时间。
- 刚滑出断口的0.28秒内允许补跳一次，避免稍晚点击直接落水。没有补跳时仍会落水返回检查点。空中镜头收近，暂时隐藏对手名字，减少遮挡。普通小跳不会获得长距离捷径奖励。
- 珊瑚海湾：1347米，多层盘旋，保留原有路线、断口、跳台、障碍和加速带。
- 落日疾驰：1341米，三段主要长直道、两个发卡弯及末段直线冲刺；加速带延长，更适合蓄能超车。
- 蓝礁天桥：1373米，宽幅S弯、上下层斜桥交叉、末段长直道；交叉处净高约56米，支撑柱通过跨桥支架避开下层路面。
- 两张新图的电脑选手采用更分散的行进线，减少在长直道中线反复贴身碰撞。基础速度、冲刺倍率和蓄能门槛相同；冲刺时长玩家6秒、电脑3秒。每局最长180秒。
- 开赛前4秒从上到下扫过赛道全景，镜头横向位置固定，没有沿路移动的球。结束自动进入2秒倒计时，也可点“直接出发”跳过。预览不计入比赛时间。
- 无碰撞地面滑行120米攒满一份冲刺，点击加速或按F/Shift释放，玩家持续6秒地面滑行，对手持续3秒，目标速度乘1.35。空中保留剩余时间，落地继续；飞跃跨过的距离不计入蓄能。撞击或落水会打断冲刺、重置未满进度；已蓄满的一份保留。对手使用相同蓄能门槛与速度倍率，按超车机会选择释放。

圆弧滑道、连续法线、水纹与水花、原创海獭、海岛栈台、近景跟拍和大名次界面沿用v0.3；没有使用参考游戏的贴图或模型。

## 玩法

- 左右拖动、屏幕方向按钮，或A/D、左右方向键转向。拖动人物可旋转工坊预览。
- 点击右下角飞跃或按空格起跳，会自动找安全落点。空中可点左/中/右按钮选择落位，不操作也会按选定路线自动落地。金色喷射跳台能跨越更远赛段。
- 看到断口警告即可起跳；缓冲杆会减速，金色水流带加速。落水返回检查点。
- 你和7名本地电脑选手竞速，按实际冲线时间排名。前三奖金200/140/100，其他名次或未完赛为0。
- 首页选择珊瑚海湾、落日疾驰或蓝礁天桥。六款泳圈可自由试穿，用比赛金币购买；装饰不影响能力。
- 暂停页显示全部8名选手排名。暂停、重开、结算、下一条路线与装备保存均已接通。切到后台会暂停比赛；短预览返回前台后继续。

## 参考与资产

主要参考[Aquapark.io官方商店页](https://play.google.com/store/apps/details?id=com.cassette.aquapark&hl=en_US)的高分辨率比赛截图，以及此前观察的[Poki版本](https://poki.com/en/g/aquaparkio)首页。对照高空滑道、角色比例、跟拍、飞跃与界面留白；没有完成原作比赛试玩。

角色、泳圈、赛道、岛屿、建筑、材质与界面均由项目代码构建。Three.js依赖随项目附带，见`vendor/LICENSE`。音效为浏览器合成音，目前没有背景音乐、联网或平台Power。模型与动作细节仍有进一步打磨空间。

## 验证与模块

`npm test`：42项全部通过，包含玩家6秒与全部7名电脑3秒的逐项计时检查、不能叠加冲刺、暂停/空中保留计时、三图完赛、675组辅助飞跃、奖金和存档。v0.8实际浏览器整局：落日疾驰54.0秒、第一名、4次飞跃、3次主动冲刺、零落水、200奖金；界面观察到冲刺剩余5.8秒。控制台error为0。历史三图画面与适配记录见`QA.md`。

`track.mjs`负责赛道与落地检测，`rules.mjs`负责共享物理、预测和规则，`glide.mjs`选择安全赛段并控制辅助滑翔，`tour.mjs`计算巡览镜头，`scene.mjs`渲染与镜头，`water-art.mjs`环境材质，`geometry.mjs`模型合并清理，`rider.mjs`角色装备，`app.mjs`界面输入。尚未在真实手机硬件或Loopit宿主验证。
