# Tidehaven v4.0 源码接入基准（已授权 GitHub → Loopit 初稿）

当前阶段：本地版本已经试玩认可，2026-11-05 用户明确授权 GitHub 中文目录备份及 Loopit 首稿。请读取本目录真实源码后接入；源码备份、平台生成和展厅发布分别记录。

## 必须保留

- 真实 Three.js 三维场景、人物行走、镜头跟随、资源动作与模型变化。
- 采集 → 地板/小屋/营火 → 石斧 → 三段跨海栈桥 → 礁岛采矿 → 加固保温 → 风雨检验 → 自由扩建。
- 地板的实际站立高度，墙体与门的碰撞，入屋后的屋顶淡出。
- 涨潮淹没海滩、淋雨/涉水失温、屋顶保护营火、加固提高恢复速度的实际规则。
- 自由选址、吸附、旋转、拆除返还、支撑校验与防止拆除后桥梁悬空。
- 设备存档、暂停/后台恢复、失败后保留进度、正常胜利与重开。
- 点击/摇杆/键盘操作，并在短屏与长屏上保持按钮可用。
- 同一存档从第一天延续到第二天；兼容 v1，并保留一次原始旧档备份。未完成第一天的玩家仍从原进度继续。
- 码头升级 → 小艇自由航行 → 外围/低潮船舱打捞 → 返航工作台 → 便携暖包 → 再次出海。
- 船体碰撞、沿甲板步行登船、靠岸下船、船上刷新继续、失温后保留物资及召回小艇。
- 工作台旁制作暖包，每次恢复 40 温暖，3 次储热；营火旁消耗 1 木料补满。船舱旧灯成为营地中的可见纪念物。

- v1/v2/v3/v4 存档兼容与原始旧档备份，同一营地继续第三天与后续天数。
- 今日补给 → 气象台预报 → 旧屋地基抬高 → 迎风石堤 → 防雨火炉 → 16 秒生存检验。
- 保存后的变长日程、六种天气及不同目标；第三天之后无结局天数，允许自然跨天与主动休息。
- 定向石堤/挡风保护、2.55 米站立高度、生产收取、磨损与修缮的实际效果。
- 自由营造免材料，保留真实库存；免费建筑拆除不凭空返还付费材料。
- 程序化岛屿、区块资源与冷却、原海域之外的船行/上岸/建造/存档，不恢复旧的 100 建筑上限。
- 空间索引、附近渲染/资源加载与离开区块后的几何释放；没有脱离设备与存储限制的“真正无限”承诺。

- 独立世界列表、命名、空白/营地起步、复制、JSON 导入导出，保留原营地和当前世界镜像键。
- 自由世界安全营造；生存世界保留挑战；日程速度、平静天气、停住时间、主动下一天设置。
- 远距离建造镜头、1/3×3 地板、吸取同款、30 笔撤销/重做、在镜头处漫游和自定义家。
- 独立地板的 freeAnchor、免费建造和原实付材料的退款规则，保存后继续有效。
- 庭院建筑/配色/灯光和实际碰撞。重建只重置当前世界编号，其他世界不被覆盖。

## 导入范围

入口 `index.html`，同目录 `style.css`、完整 `src/`、完整 `vendor/`。无需网络请求外部素材，不需要 npm 构建。静态服务器需把 `.mjs` 作为 JavaScript 返回。

平台接入时应读取实际源码，连同 `voyage*.mjs`、`frontier-state.mjs`、`survival*.mjs` 、`spatial.mjs`、`world-state.mjs`、`sandbox.mjs`、`decor-world.mjs` 模块，在此规则基准上仅适配宿主、资源路径、打包和输入；不根据游戏名重新生成另一款游戏。本地通过与平台通过分开记录。

只做宿主、打包、资源路径和输入适配；不要改写为另一款游戏，不用 iframe 外链冒充源码接入。此次仅生成草稿，不发布展厅。先验证真实读取了 index.html、style.css、全部 src/ 和 vendor/，再验证平台首屏、采集、独立世界、3×3、撤销重做、保存及手机布局。平台音乐与 Power 可在核心接入稳定后另行评估。
