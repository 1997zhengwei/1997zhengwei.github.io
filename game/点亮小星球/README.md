# 点亮小星球 · Pocket Planet: Horizons

本地验收版本 v0.9.0，准备接入既有 Loopit 多人项目。源码上传和平台联机验收是两个阶段；不能把本地通过当作平台已通过。

运行 `npm start`（Node.js 22+），打开 http://127.0.0.1:8820/。`npm test`：159项。Three.js 已含本目录 vendor 和许可证，无需安装依赖。手机摇杆/WASD移动，自动射击，无职业、Dash或技能按钮。

三章长条地图、三座基地、1–60级、每三级外观变化、四种武器；第三章双发、星兽宠物、坐骑和三位不同头目。采集/战斗→建补氧/防御→升级装备→深入→回基地。八人自动分厅、独立角色钱包、共享公共设施、区域难度。只在基地回血，补氧站只补氧。

**接入前读 LOOPIT_HANDOFF.md。** 入口 index.html / starpath-main.mjs，starpath-server.mjs 是本地HTTP/SSE参考服务器，需要迁移到平台支持的权威房间与存储，不能直接用静态托管运行Node服务器或指向开发机。

不含用户档案、凭据、测试身份或服务器日志；正常首次进入从1级开始。不能默认将本地匿名身份或另一游戏存档映射到平台访客。

验证记录见 QA.md；本地159项通过。GitHub作为固定源码基线，平台适配与部署版本记录另行维护。
