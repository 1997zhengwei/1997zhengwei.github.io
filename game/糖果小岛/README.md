# 糖果小岛 v6 · 纯解压合集世界（3D ASMR）

在 v5（`../crystal-peel-asmr-v5`，一颗一颗的纯解压版）的手感基础上，不再一颗一颗过：**一座小岛上一圈种着 8 个糖衣水果，随便剥哪个都行，吃掉的过几秒原地再长出来。**

## 玩法
- **自由三维视角**：拖空白处（天空/地面/后排）左右转、上下改俯仰（贴地平视 ↔ 接近俯视）；滚轮或双指捏合缩放（近=特写一颗，远=整岛全景）；空白处双击在特写/全景间切换。拉近时松手会吸附到最近的果子，拉远时不吸附。
- 屏幕上够大的果子才能摸（≥ 最大那颗的 72%），远处小的只是风景，拖它们那块就是转视角。
- **快划 / 慢拉 / 画圈**：和 v5 一样，而且一笔能跨好几颗果子（从正面划到旁边那颗）。剥完一笔，镜头会把那颗慢慢转到正中。
- **剥光 → 咬三口**：点在果子附近就算一口，"再咬一口 1/3" 提示跟着果子走；吃完"还会再长哦"。
- **再生**：空位 3.5–7.5 秒后从地里"啵"地长出一颗新果子（不和左右重样），糖壳再从上往下一块块结晶回去（叮叮往上走的玻璃音）。没有晶洞/稀有奖品/图鉴（用户不要收集）。
- **六种果子**：草莓、香橙、蜜桃、蓝莓、青提、山楂串。
- **碎糖**：撒满整座岛（高度场越堆越高），按住碎糖堆拖动可以拨弄；攒到约 220 片吃完一颗时自动按颜色倒进右上角水晶罐（520 片一罐）。点罐子看吃掉几颗、装满几罐。

## 运行
```bash
python -m http.server 8937 --bind 127.0.0.1   # 在本目录
# http://127.0.0.1:8937/ （?dev：__game.state / front() / clearFront() / biteFront() / eatFront() / regrowAll() / pour() / spin(a) / view(pitch, zoom) / cam）
node --check rules.js && node --check game.js
```
存档键 `crystal-island6-meta-v1`（吃掉几颗、罐子、引导），静音键 `crystal-island6-muted-v1`，不影响 v1–v5。

## 实现要点
- 每种果子的模型和切壳只算一次（`cacheType`，6 种约 1.4 s，开场卡片期间完成），之后长出来的都是克隆：几何体共享（`geometry.userData.keep` 不释放），材质克隆后各自注入咬痕 uniform。
- 每颗果子一组 12 个球形缺口 uniform（注意 `Vector4` 默认 w=1，必须显式填 0）。
- 性能：闪光精灵只给 1/3 的壳；阴影隔帧更新。无头 Chrome 375×812@2x 约 57–95 FPS（v5 单颗约 100）。
- 无头 Chrome 真实鼠标：快划、跨果子一笔、慢拉、低角度/俯视/滚轮拉远全景/双击回特写、咬三口、再生结晶、拨碎糖、倒罐全流程无报错。拉远看到更多果子时约 57 FPS。
