# Loopit 源码交接 · 黑洞都市 · v0.7.0

- 中文目录：`games/黑洞都市-自由吞噬/`，默认入口`index.html`，也可使用`arena.html`。
- 先完整读取并导入本目录；包括`src/`、`vendor/three.module.js`、`vendor/three.core.js`。使用UTF-8和可解析.mjs的HTTP环境，不依赖开发机localhost。
- 保留真实3D与四面八方移动、镜头、建筑碰撞/剖切、实际吞噬成长、追逐与避让、电脑安全返场和保护、远处物资恢复、120秒比赛与前三奖金。
- 保留已确认的黑色人形“奇点行者”、向地下收缩的立体漏斗、吸积流、下沉动画、六款换装和仅外观属性。
- 优先手机竖屏：拖动/点地面/小地图操作；桌面WASD为辅助。暂停、被吞、自然结束、换装、购买、重开和刷新恢复均应复测。
- 固定游戏规则为`src/arena-rules.mjs`，截图仅用于画面参照，不把原生3D场景替换为背景图。`parkour.html`是历史参考，不作为当前玩法入口。
- 核心接入稳定后才评估音乐与Power；平台适配之外的玩法改动另行讨论。
- 本地电脑竞技不标为真人多人联机；线上榜单与云存档尚未实现。

验收先对照README和QA，再验证：开始→移动与吞物→大小变化→吞噬/逃避→电脑返场→自然计时或被吞结算→换装/重开→刷新存档。源码上传、平台生成、实际可玩和公开发布分别判断。
