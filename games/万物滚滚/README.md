# 万物滚滚 · ROLL IT ALL

本地三维滚动收集跑酷，v0.8.3。参考块魂的真实黏附、可见累积和尺度变化，采用自动前进、左右选路的短局结构。

## 启动

双击同目录的 `启动试玩.cmd`。也可以执行 `python serve.py --open`，默认地址为 http://127.0.0.1:8795/ 。只监听本机地址，不需要安装运行依赖或连接CDN。请通过本地服务打开，浏览器使用支持WebGL2的Chrome/Edge。

## 怎么玩

- 鼠标或手指左右拖动选路；也可以使用A/D、方向键。
- 左右按钮轻点切换选线，按住连续转向；松手就稳住。
- 空格或右下角起跳，跨过缓冲杆。绿色粗圈与“＋”表示当前可吸收，红色粗圈与“！”表示撞击危险；大物件可绕开或跃过。护盾、冲刺及短暂保护状态会在下方图例显示。
- 收集蓄满后，按F/Shift或左下角使用聚合冲刺（初始四秒，续航可升级）：加速、扩大吸附范围，并抵挡磕碰。
- 右上角或Escape暂停。暂停菜单可以开关全部声音。

三条路线各有桌面、房间/花园、街区三站。v0.8.2延长最后的街区，球长大后还能继续收集一段车辆、小屋与路边物件；前两站和操作、积分规则保留。相同物品保持固定比例，球从约10厘米开始长大；先卷小玩具，再尝试家具和车辆。物品实际黏在球上，随球旋转。

## 成长积分、装扮与能力

单人成长挑战，不生成对手或排名。到终点或180秒时间结束时，按本局达到过的最大直径结算成长积分：每满10厘米得2分。50厘米10分、1米20分、5米100分、10米200分、15米300分。被撞小后已达到的最大尺寸与积分不回退；主动重开或返回主页不结算未完成的一局。同一局只到账一次。

成长工坊分为服装、尾迹、能力三栏。保留六套服装；五款尾迹选项包含不显示尾迹，另外四款具有真实移动轨迹与脚下光圈。服装、尾迹只改变外观。

| 能力 | 初始 | Lv.1 / Lv.2 / Lv.3 | 各级价格 |
| --- | --- | --- | --- |
| 聚合续航 | 4秒冲刺 | 5 / 6 / 7秒 | 180 / 360 / 600积分 |
| 磁力范围 | 标准接触范围 | 额外增加球半径的8% / 16% / 24% | 160 / 320 / 560积分 |
| 缓冲护盾 | 0次 | 每局抵挡1 / 2 / 3次 | 200 / 400 / 700积分 |

能力永久保留、下一局生效；每局护盾补满，冲刺免罚或保护期不会消耗护盾。碰到还卷不动的大物件或障碍杆会减少3.5%体积（直径约减少1.2%）、减速0.9秒，之后有1.1秒保护；球上超过8件时掉1至3件，其余模型保留。修复了9至39件时因零索引错误一次清空附着模型的问题。

28种图鉴物品、三件路线纪念物及三条路线保留。积分、外观、尾迹、升级和纪录保存在当前浏览器。沿用普通存档键`roll-it-all-v1`，旧金币按原余额作为积分使用，已购服装、发现和纪录保留；新增尾迹与能力从默认状态开始。`?qa=1`使用独立测试存档`roll-it-all-v1-qa`，测试购买不会扣玩家积分。

## 美术与声音

v0.8.3修复场景交界的镜头遮挡：镜头升高时，上一场景挡住角色视线的顶面与墙体会临时隐藏，视线恢复后还原；遮住角色的大件散落物会淡出，仍可正常碰撞和收集。章节提示改为短时小标签。成长、积分、路线长度和存档规则保留。

v0.7.0改为鲜明卡通方向：共享四色阶明暗、低面数轮廓、饱和的日常物件配色，减少奶油色反光和远雾。桌面使用清晰木纹，晴日房间使用草席纹理，玩具房使用木地板与局部彩色地垫，野餐路线使用格纹桌布和开阔草地。街区补齐道路标线、斑马线、店铺招牌和条纹遮棚；主页、换装、图鉴与操作界面统一配色。纹理、招牌和天空均由本地代码绘制，没有加入外部下载依赖。


真实Three.js场景，原创程序模型和材质。桌面有厚度、边缘和下方房间地面；室内有木地板、地毯、窗帘、沙发、书架、墙面和天花板；街区有固定尺度房屋、商店、窗户、遮篷、路灯和绿地。场景采用自然分组和占地避让，避免把房屋、车辆排成互相穿插的阵列。

模型、角色和《Pocket Parade》配乐由本项目制作，没有使用参考游戏的模型、贴图或音乐。Three.js r186遵循MIT许可，见 `vendor/LICENSE`。配乐生成方法见 `assets/audio/README.md`，游戏运行不需要NumPy或FFmpeg。

v0.8.1仅加强提示：白边加粗红绿圈、近处浮动加号/危险符号、常驻图例与保护状态说明。稀有物件的地面圈也按真实吸收能力标色，金色收藏名称仍保留。

## 开发与验证

`npm test` 执行规则、几何和三条路线的完整流程检查。实际浏览器试玩记录和画面检查见 `QA.md`。`node scripts/check-package.mjs` 核对运行文件、相对导入和音频文件。

这是保留自动向前移动的跑酷改编，和原作的自由探索结构有区别。场景、比例和物品摆放已经重做；模型细节与整体美术仍有提升空间，不宣称达到原作同等制作水准。
