# 冲沙淘金 · Sluice Trail

本地试玩 v0.6.2。用手指或鼠标在 3D 沙土剖面上挖沟，放水冲出藏品。

## 玩法

- 从发光的水口往下挖。沟渠要经过宝石，并通到下方的筛盘。水口没接通时，水口会闪光并显示箭头。如果放水后一直没有水流进来，会提示"水口还没接通"。
- 「放水」打开水流，电脑上也可以按空格。水沿挖开的空间往下流，碰到挖松的宝石会把它带走。岩石挖不动。
- 淘到的宝石会飞进沙盘下方的展示架。所有宝石都入筛后就结算。

## 关卡（24 关，4 章）

| 章节 | 关卡 | 新东西 |
|---|---|---|
| 河谷初探 | 1–8 | 基础挖沟、双水口、指定筛口 |
| 红土高原 | 9–14 | **红土**：能挖，但挖一格算三格挖沙量（偏红色的土层） |
| 冰川河谷 | 15–20 | **冰块**：挖不动。水贴着冰流一会儿（约 9 拍），冰就会一格格融化。宝石也可能冻在冰里 |
| 金脉深处 | 21–24 | 红土和冰块一起出现，加上多水口和指定筛口 |

每章第一关第一次进入时，会弹出新机关的说明。关卡数据在 `src/flow.js` 的 `sites`：`rocks` 是椭圆岩石，`clay` 是椭圆红土，`ice` 是矩形冰块 `[左列, 上行, 宽, 高]`。

## 三星评分

- ★ 淘出全部宝石
- ★ 用水量不超过刻度线（顶部 💧 条）
- ★ 挖沙量不超过刻度线（顶部 ⛏️ 条）

三颗星分开计算，取每关历史最好。刻度来自 `tools/solve-pars.mjs`：自动求解器先找出一条省水省沙的沟，再按"用水 ×1.3+12、挖沙 ×1.35+10"放宽。改关卡后重跑这个脚本，再把结果更新到 `src/flow.js` 的 `pars`。

沙盘里还有发光的「沙金」。它不影响通关，冲进筛盘可多拿金币，但要多挖、多用水，需要自己权衡。

## 画面与手感（v0.6.0）

- **通关演出**：最后一颗宝石入筛时有约 0.75 秒慢动作，镜头推近筛盘，同时出现金光和冲击环。展示架上的宝石会依次跳起发光。拿到三星时还会下一阵金币雨，配胜利小调。
- **连淘**：1.1 秒内连续入筛的宝石算连淘，二连 +5、三连 +10……依次递增，会弹出大字并换音色，结算时显示在「连淘奖励」一行。同一关里每颗宝石的入筛音一颗比一颗高。
- **辉光（bloom）**：宝石、金币、金尘和水面高光会额外渲染到一个半分辨率画面里，模糊后叠加上去。手机卡的话，地址后加 `?lowfx` 可以关掉。
- **章节氛围**：
  - 红土高原：远山热浪、橙色天光、飘浮的红尘。
  - 冰川河谷：飘雪，水口下挂着冰溜子。
  - 金脉深处：傍晚暖光，空中有发光的金尘。
- **水**：水流顶边和积水面有一条亮的水位线，水头带白色水花，宝石入筛时溅起水雾。沟壁也会被打湿变深。
- **沙层小细节**：沙里埋着小石子、贝壳、骨头和草根，挖开时会弹出来。多数关卡藏着一只小螃蟹，挖到它会跳出来跑掉。这些都只是装饰，不计分。
- **声音**：冰块融化有清脆的叮声，小装饰弹出时有轻响，小螃蟹有吱吱声，连淘和三星各有专门的音效。

## 长期内容

- **矿脉地图**：一共 24 关，分 4 章，通关上一关解锁下一关。地图上显示每关的星数，以及最佳用水和挖沙记录。没有成绩的旧存档显示「已通关」，未过关的关卡显示星级刻度。打开地图或淘金铺会暂停当局，关闭后继续。
- **淘金铺**：
  - 道具：🧨 炸药（点一块岩石炸开）、🧲 磁石（本局吸附宝石的范围变大）。
  - 外观：水色 5 种（星河是彩虹水）、挖沙拖尾 4 种、筛盘 4 种。
- **金币来源**（v0.6.1 下调）：
  - 宝石：金砂 5、翡翠 10、蓝晶 12、日光红晶 13、琥珀 15。
  - 沙金每粒 3，每颗星 +8，首次三星 +40，连淘每多一颗 +5。
  - 每天前 3 次通关，宝石和沙金的金币翻倍。
- **节奏**：首轮打完 24 关大约攒 2000 金币，够买 2–4 件外观。全部 11 件外观合计 6950 金币，大约还要重刷 60–70 次才能买齐。估算方法见 README 末尾。
- v0.4.0 的图鉴和淘金袋已按反馈删除。

存档放在浏览器 localStorage（`sand-sluice-save-v2`），旧版的通关记录会自动迁移。

## 运行

在本目录运行 `npm start`，然后打开 `http://127.0.0.1:8956/`。Windows 也可以运行 `node launch.mjs`。如果要换端口：`PORT=8966 node server.mjs`。

调试：地址后加 `?dev`，可以在控制台用 `window.__sluice` 查看存档和模型、跳关。

## 源码入口

- `index.html`：试玩入口，包含 HUD、地图、商店和结算卡。
- `src/game.js`：交互、关卡状态、三星结算、地图和商店界面、音效。
- `src/flow.js`：24 关布局、章节、星级刻度、沙金位置、挖沙（含红土）、冰块融化、炸岩和水流判定。
- `src/progress.js`：存档、星级记录、每日加成、商店目录。
- `src/world.js`：3D 场景，包括相机自适应、连贯水面（半分辨率叠加后阈值化）、湿沙贴图、宝石光晕、展示架、外观切换和爆破特效。
- `src/sand.js`：分层沙纹、可挖沟壁和湿沙着色。
- `src/models.js`：岩石和宝石模型。
- `tools/solve-pars.mjs`：自动求解每关的参考用水量和挖沙量。`--map 12` 用字符画打印第 12 关和求解出的沟。求解器找不到路线时，可以在关卡里写 `route`（手画的参考路线），由它来算刻度。最后一行输出可以直接粘贴到 `pars`。

全部依赖都在本地，不需要安装 npm 依赖。借鉴《Dig This!》拖动挖出路径和重力解谜的手感，地形、水流规则和模型为原创实现。Three.js 许可证在 `vendor/LICENSE`。

## 经济估算

先跑一遍 `node tools/solve-pars.mjs` 确认关卡没问题。外观价格：水色 300 / 500 / 900 / 1500，拖尾 250 / 500 / 900，筛盘 350 / 650 / 1100；道具：炸药 120、磁石 80。调价格改 `src/progress.js` 的 `SHOP`；调收入改 `src/flow.js` 的 `finds[].score` 和 `src/progress.js` 的 `recordClear`。
