# 冲鸭！障碍派对 · 源码交接

版本0.6.1。GitHub目录：`games/冲鸭-障碍派对/`，游戏分支 `codex/krabby-patty-flip`。源码是玩法和视觉基准。此次交付仅上传GitHub，尚未进行Loopit源码接入或发布。

## 读取与启动

先读取README.md、src/下全部模块、assets/maps/和vendor/，从index.html启动。无构建步骤、无网络素材依赖；支持静态HTTP。开发运行可用Python serve.py或npm start，规则测试npm test。vendor内的Three.js模块及MIT许可需一起保留。

## 必须保留

- 全屏真实3D、手机竖屏摇杆+跳跃按钮，空中第二次点击飞扑；WASD/方向键+空格为桌面辅助。每次离地只允许一次飞扑。
- 五图和第二位S弯，检查点、实际断口、冰面、弹簧、横向传送带、摆锤与喷发预警。
- 11位对手：1新手、2熟练、3高手、5技巧型。保留每局随机分配与偶发真实失误、碰撞和恢复；使用同一物理上限，技巧型能在安全直道主动跳跃飞扑。
- 只有一种比赛；按实际冲线排名，冠军200/亚军140/季军100，赛道收集仅前三结算。第4名起及未完赛收入0；前三冲线后玩家仍能继续到终点查看真实差距。
- 六角色、三个独立饰品槽、25件付费配件、8种配色。试穿不扣钱，保存只用已拥有物品；购买和奖励不重复到账。当前存档version4，继续兼容既有金币、装备和各图记录。
- 高清商品图、彩色渐变羽翼、金属/面罩反光、流光尾迹、拖动转身、收翼/展翼、无重影品质标签。
- 暂停同时暂停比赛与对手；结果页等待旧触点释放后启用重开，避免跳跃触点误触重开。
