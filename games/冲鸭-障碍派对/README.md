# 冲鸭！障碍派对 · PARTY DASH v0.6.1

全屏 3D 障碍竞速。五张独立赛道、11 位风格与水平各异的电脑对手，以及可购买、染色和组合的装饰工坊。

## 本地试玩

下载本目录后，双击 `启动试玩.cmd`；也可在本目录执行 `python serve.py --open`。

新版入口：http://127.0.0.1:8792/?v=6 。资源随目录携带，可离线运行；通过 HTTP 服务打开。

手机左手摇杆移动，右手跳跃；空中再点一次飞扑。电脑 WASD / 方向键 + 空格，Esc 暂停。每次离地只允许一次飞扑。

## 五张地图

大厅点「选择地图」，五图全部开放。选图会保存，每张图分别记录个人最佳成绩。

| --- | --- | --- |
| 云端大奖赛 | 382 米 | 保留经典七段路线、加速带、逆行带、窄桥捷径和摆锤 |
| 云海 S 弯 | 342 米 | 地图列表第二位；两组真实连续 S 弯、弯心走线、弯后机关与云桥接力跳 |
| 极光冰川 | 312 米 | 冰面惯性、侧风桥、自动弹簧跳台、雪峰连跳；冰晶与极光场景 |
| 霓虹机巧城 | 338 米 | 左右交替的横向传送带、连环摆锤、加速港和接力桥；夜城场景 |
| 熔岩遗迹 | 348 米 | 先预警后喷发的火柱、浮石连跳、熔河双路桥；古城与熔岩场景 |

赛道拥有各自的机关配置、检查点和 AI 路线。电脑与玩家最高基础速度均为 7.3，使用同一套跳跃、飞扑、碰撞和复活物理。每局混合 1 位新手、2 位熟练选手、3 位高手和 5 位技巧型选手，并打乱水平与角色的对应关系；反应、节奏、选路、飞扑和过弯保守程度不同；技巧型会在安全直道主动跳跃飞扑，并更积极选择捷径。偶发判断失误会导致真实撞击或掉落，恢复后继续竞速；头顶星星和身体倾斜标示失衡。只有一种比赛，按实际冲线顺序排名。每图最多 150 秒；前三名冲线后，其余玩家仍可继续跑到终点，并查看与第三名的真实时间差。

## 高清与炫彩显示（v0.6）

角色和商品缩略图改为本地 512×320 渲染，按实际模型完整取景；未购买商品也显示完整色彩。角色轮廓更圆滑，面罩与金属增加清晰的反光；羽翼修正渐变贴图坐标，呈现蓝紫、青金等彩色层次。尾迹增加彩色光带、亮芯与星点。高分屏工坊按最高 2 倍像素渲染，比赛按最高 1.6 倍控制开销。

本轮仅改变三维显示与工坊缩略图，沿用 v0.5 的对手、地图物理、奖励和存档。

## 装饰工坊

六款角色、25 件付费配件、3 个不佩戴选项、8 种免费装饰配色。头饰、背饰、尾迹分开购买和搭配，外观不影响比赛能力。

v0.3 重做了高级饰品：曲面分层羽毛、蝶翼膜与脉络、星纹披风、镂空冠架、切面宝石、金属与珠光材质、连续光带尾迹。新增「日冕神冠」「曜金凤凰羽翼」「彗星龙焰」。羽翼跑动时收拢，腾空时展开；工坊支持拖动转身和收翼 / 展翼。

试穿不扣钱；购买只扣一次，保存时只装备已拥有物品。随机搭配只选已拥有配件。奖金为冠军 200、亚军 140、季军 100；仅前三名可结算赛道收集。第 4 名及以后收入为 0，未完赛也为 0。

旧版金币、角色、配件、配色、胜场和云端大奖赛纪录保留。更早的短图纪录继续归档 classic。存档保存在同一浏览器、同一地址的 localStorage；旧难度选项在升级时移除，金币和已购装备保留。

## 源码与验证

- `src/tracks.mjs`：五张地图的路线、机关、金币和 AI 区域。
- `src/rivals.mjs`：每局分层阵容、独立随机序列与反应参数。
- `src/curved-road.mjs`：与碰撞中心线一致的弯道网格和护栏。
- `src/course.mjs`：物理、冰面、弹簧、喷发碰撞与电脑对手。
- `src/environments.mjs`：云端、冰川、夜城、熔岩四种场景。
- `src/couture.mjs` / `src/ornaments.mjs`：配件模型、材质与动态尾迹。
- `src/progression.mjs`：商品、购买、迁移与奖励。
- `src/scene.mjs` / `src/app.mjs`：渲染、镜头、选图、触控、工坊与结算。
- `assets/maps/`：从真实本地渲染画面保存的选图缩略图。
- `tests/`：28 项测试，执行 `node --test tests/*.test.mjs` 或 `npm test`。
- `QA.md`：当前验收摘要与代表性实机画面。
- `LOOPIT_HANDOFF.md`：供后续平台读取源码的交接说明。
- `SOURCE_MANIFEST.json`：上传文件的 SHA-256 与 Git blob 校验值。

运行时仅依赖目录内 Three.js（MIT，见 vendor/LICENSE）；模型、纹理和 UI 由本项目代码构建，音效由 Web Audio 合成。保持此前参考成熟派对竞速游戏的全屏、鲜亮、易读方向，未使用对方游戏素材。

本地电脑竞速，尚无真实联机、在线排行或云存档。本目录为已授权的 GitHub 源码交付，尚未接入或发布 Loopit。`?qa=1` 使用隔离测试存档，`render_game_to_text()` 为只读状态接口。
