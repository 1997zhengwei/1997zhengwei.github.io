# 屋顶疾行 · ROOFTOP FLOW v0.5.0 · 屋顶寻宝

一款本地第三人称三维跑酷寻宝游戏。参考 Rooftops & Alleys 官方预告和截图中的立体场景、身体重心与连续动作，自行选择跨楼、沿墙、攀上或折返。看小地图寻找宝藏，甩开三位追逐者。当前仍是浏览器原型，画面、动作丰富度和地图规模不等同于商业原作。

v0.5.0 保留原来的起始路线，向北与向东扩为 25 座屋顶、6 个自由练习出发点。21 座屋顶可藏宝，每关在已检查的安全区域内随机选择具体落点，避开上一关的藏宝屋顶；失败重试保留本关位置。关卡编号、解锁、余额与已拥有服装会保存。

装备店现有 6 套服装、3 款独立背包、3 种足迹特效与 3 件永久实用道具。默认旧灰卫衣与基础蓝衫保持朴素，高价款增加立体背心、工具袋、反光袖环与金属滚边；背包由基础帆布升级至光导硬壳、紫金远征结构。道具每次出发恢复使用次数，同一时间装备 1 件。

## 开始试玩

双击本目录的 **启动试玩.cmd**，或在本目录运行：

```powershell
python serve.py --open
```

浏览器打开 http://127.0.0.1:8796/ 。需要 Python 3 和支持 WebGL2 的现代浏览器。也可运行 `python serve.py --port 8797 --open` 更换端口。不要直接双击 index.html，浏览器的模块加载需要本地 HTTP 服务。

无需 npm install，Three.js 已随源码提供；游戏不依赖 CDN 或远程素材。服务只监听本机地址。

## 规则与内容

- 寻宝每关从 21 座可藏宝屋顶中抽取一个，在安全落点附近随机放置宝箱；站立支撑面、箱体空间与寻路可达性均检查。下一关避开上一关的藏宝屋顶，重试保持同一落点。白色箭头是玩家，金色菱形是宝箱，红色圆点是追兵实际位置；小地图北向固定，可点击展开。靠近宝箱并站稳会自动过关。
- 初始 3 条命。每次失足扣 1 条并返回安全屋顶，重生后有 2 秒保护；生命归零失败。被追逐者抓到立即失败，与剩余生命数无关。实体墙阻挡抓捕，不会隔墙或跨楼层判定抓到。
- 第一次移动后开始计时，并给玩家 4 秒领先。三位追兵速度分别为 6.7、6.35、6.05m/s，低于玩家默认全速 9.6m/s；使用实际走路、跳跃、翻栏、攀爬和滑铲寻路。暂停或展开地图冻结所有角色，慢动作同时影响双方。
- 寻宝胜利奖励为基础 16 币 + 每条剩余生命 2 币 + 无掉落奖励 3 币 + 45 秒内速度奖励 3 币，最多 28 币；每关连招另外最多收下 6 币。奖励仅结算一次，失败没有寻宝奖金，已收下的连招徽币保留。通关保存下一关编号和上一处藏宝屋顶；没有随关数增加追兵速度。
- 老城屋脊、花园旧巷、施工街区，共 25 座可落脚屋顶；没有强制路线。地图有限，不是程序生成的无限城市。“自由练习”保留不受追逐、生命和寻宝目标约束的探索。
- 翻栏、攀上、沿墙、有效滑铲及跨越落地积累连招。5.2 秒内接续动作提高倍率，落稳后连招超时收下。空翻需跨越足够距离并落稳才加分。
- 每 180 连招分换 1 徽币（向下取整，单次至少 1）；同一物体 4 秒内不重复计分，35 秒内重做减半。徽币即时保存，用于装备店。服装、背包和足迹只改变外观；实用道具效果见下方。
- 自由练习失足回到刚才站稳的屋顶，没有罚时；未收下的连招中断，已赚徽币保留。B 记住自己选择的宽敞落脚点，X 返回并停止前进；寻宝中禁用这些返回功能。
- 自由练习可暂停后“收工”，保存游玩距离、已赚徽币及最佳连招。寻宝可暂停、重试或放弃。关闭页面会失去尚未收下的连招。没有虚构 AI 排名。
- 旧最佳时间和影子仍保存在原存档中，自由街区不显示也不播放旧赛道影子。币、服装和新最佳连招保存在当前浏览器；换浏览器、清理站点数据或换端口使用另一份存档。
- `?qa=1` 使用独立测试存档，测试不会消耗普通存档的徽币。

运行 `npm test`。规则测试与实际浏览器试玩证据见 [QA.md](QA.md)。

## 素材与范围

人体、基础衣物和呼吸待机使用 CharacterCreator / MakeHuman 的 CC0 输出资产；奔跑、攀爬、滑铲和翻滚使用 Quaternius Universal Animation Library 1/2 Standard CC0，建筑模块来自 Downtown City MegaKit Standard CC0。砖墙、混凝土贴图和 Venice Sunset 环境光来自 Poly Haven CC0。街区布局、玩法、接触 IK、空翻、配饰和界面为本地实现。没有使用参考游戏的模型、贴图、品牌或音乐。完整说明见 [assets/ATTRIBUTION.md](assets/ATTRIBUTION.md)。Three.js r186 及加载器/几何工具使用 MIT 许可，原文见 `vendor/LICENSE`。

`assets/runner.glb` 已预先编译，正常试玩不需要构建。若需从 `assets/character-source/` 重建人物，可安装 Python 的 NumPy 后运行 `python tools/compile_runner.py`；该步骤只用于素材开发。

人体动画重定向可运行 `node tools/compile_motion.mjs`，使用附带 CC0 源动作。城市模块来源记录在 `assets/city-kit/sources.json`，授权原文随素材提供。

桌面实跑与竖屏检查的版本和证据见 QA.md；真实手机、音频混音和性能尚未进行设备实测。背景远楼用于城市景观，当前可落脚的玩法空间是 25 座主楼顶及相连设施；没有多人、编辑器、第一人称或完整街面跑酷。首次加载需准备人物和建筑贴图。
