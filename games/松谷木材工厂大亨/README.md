# 松谷木材工厂大亨

本地 3D 试玩版 v0.3.1。从松谷锯木厂起步，叫原木车、锯切、堆板、装车。首单交满 12 块后，留出 $240 即可在工业园地图建河湾烘干厂。续建红杉精刨厂和雪岭木构厂会增加新的工序、成品与订单。雪岭每 2 块毛板压成 1 根承重木梁。

点「园区」进入连片的 3D 工业园，拖动和缩放即可查看各地块。点「下一块地」可查看建厂成本和前一座厂的交付要求。建成第四座厂后，后续地块会继续沿园区道路生成，独立经营并接入同一企业资金。点任一已建厂牌，选择「进入厂区」放大到工位。

全景中的生产按钮贴着所在工位。点升级牌或扩建牌直接用游戏资金购买对应升级，点旁边的取景图标或库存卡可拉近镜头。近景下生产按钮移到底部，点「全厂」返回总览。点左上角订单条可查看奖励和提示。桌面用 Q 运输、W 锯切、E 发货、R 后加工。

每座厂的班组和机器独立升级，所有工厂共享资金。页面处于前台时，切到别的工厂仍会推进已启用的自动生产。扩建料场会在现场新增料位，设备可升至 15 级，订单会持续续签。荣誉馆记录成品库存峰值、累计交付、建厂等成就，可保存荣誉卡。

荣誉馆里的「生成荣誉卡」会把当前头衔、商业版图、工厂数量、累计交付、订单数、库存峰值及已获勋章绘制到 1200×1500 的 PNG 证书，可预览并下载。资金、库存、班组、订单和在途车次保存在当前浏览器。旧版松谷存档会自动迁移。

双击工作区根目录的「启动松谷木材工厂.cmd」，或在本目录执行 `node server.mjs 8944` 后打开 <http://localhost:8944/>。运行需要 WebGL 和 Node 18+。依赖已包含在项目内。执行 `npm test` 可检查经营规则与存档，`npm run build` 可生成静态 `dist/`。

参考 [Idle Lumber Empire 的 iOS 商店页](https://apps.apple.com/us/app/idle-lumber-empire-wood-game/id1552153525)与[发行商的图文案例](https://appquantum.com/publishing-use-cases/Idle%20Lumber%20Empire%20Case%202024.pdf)，借鉴了近距离呈现车辆、木纹和加工工序的方式。松谷厂区、设备、车辆模型及界面均为程序生成的原创设计。
