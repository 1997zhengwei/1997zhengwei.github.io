# Loopit 源码接入说明：比奇堡·绳索搭档

这是用户已认可并授权备份/接入的完整本地成品。读取本目录实际源码与资源再接入，不从标题或截图重新设计另一款游戏。当前目标是 Loopit Lab 初版草稿，不是展厅发布。

## 入口与依赖

主入口 `index.html`，静态 HTTP 即可运行；无 npm 构建、远程 API、CDN 或 shared 目录依赖。所有相对导入均在本目录。`vendor/three.module.js` 继续导入同目录 `three.core.js`；必须完整保留这两个文件和许可证。模块 URL 中的 `?v=elastic-2` 是缓存版本参数。

## 必须保留

1. 海绵宝宝和派大星的真实三维程序模型与现有 01/02 运动装，不能换成方块、贴图或其他造型；`team.html` 和 evidence 图片给出外观基准。
2. 左右小跳由玩家控制：按钮、方向键、A/D；按住重复、松手停止，箭头指向当前受控搭档。不要恢复被用户否定的自动向前两步。
3. 主按钮/空格换手。轻松模式可按住连续接力，挑战模式要求等待合法落脚。绳长在下一次换手生效，切换不能瞬移人物。
4. `physics.mjs` 的真实弹簧回拉与阻尼、重力和伸长上限；`rope.mjs` 的松垂、惯性与回弹。小跳必须影响搭档的实际飞行，不能只画抖动的绳子。
5. 固定 1/120 秒物理子步、起摆辅助及小跳站位辅助；不要把大摆荡改回固定圆弧。场景为侧视三维、运动在垂直平面。
6. 三段主线、28 次接力、蟹黄堡、水母、护盾、检查点、一次性结算、完整重试和通关后实际生成新平台的无尽路线。
7. 原中文界面、镜头跟随、手机点按、静音和暂停/失焦清输入。

## 接入范围

只做 Loopit 宿主、构建、路径、触控和尺寸适配。可以把本地 Three.js 换成平台已有相同版本模块，但不得丢失真实人物和弹性玩法。若源码无法读取，明确缺失文件，不猜测也不声称完成接入。

## 验收

- 开始 → 左右各小跳 → 身体移动、绳子响应 → 主按钮换手 → 控制对象切换。
- 轻松模式持续接力，放开小跳后不再自动蹦；水母/掉落 → 重试后角色位置、速度和输入干净。
- 暂停/继续、小跳途中失焦、绳长调整、通关/继续无尽。
- 400×580 与 390×780 的按钮可见、可点，无溢出。平台预览和独立页分别检查。
- 运行本目录 24 项规则/物理测试；记录实际源 commit、生成版本与平台验证，音乐/Power 不先于核心接入。
