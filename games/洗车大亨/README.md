# 泡沫海岸 · 洗车大亨

本地真实 3D 经营游戏，v0.3.0。中文，桌面/手机均可玩。无运行时 CDN/npm 依赖。

本版按用户提供的两张游戏截图统一视觉：深蓝描边与厚底彩色按钮、Nunito 粗圆数字/字母和中文粗体、半透明薄荷面板、冷灰地面及深蓝车道。左侧为设备/员工/装扮，右下黄色按住精洗、绿色扩建；原存档与经营规则继续使用。

v0.2.1 修复共享出口抢道：洗完按先后预约放行，前车完全通过合流区后再让下一辆驶出；等候车辆留在本车道，后续顾客不能抢占工位。上蜡增加金色蜡膜、旋转抛光盘与漆面高光，阶段基础时长由 3.6 调为 4.8 秒，让过程更容易看清；原售价和奖励不变。

v0.3.0 新增三种原创豪车：星耀 GT 超跑、曜石行政座驾和云境豪华 SUV。每店洗满五辆后开始出现，后续间隔约 4–7 辆洗车量再到访，同时最多两辆未服务的豪车。完成原三阶段后，还需进行轮毂精洗、双层镀晶或内饰蒸汽护理，才结算更高基础售价与 55%–65% 额外护理奖。按住原精洗按钮或交给员工/自动设备均可完成，不设置倒计时失败。增加可点击的到店提示、VIP 标识与光环、完成礼花和扩散光圈；原排队出口及存档继续使用。

## 运行

```powershell
python serve.py --port 8803
```

打开 `http://127.0.0.1:8803/`。初次玩家独立档：`http://127.0.0.1:8803/?slot=coast`。

```powershell
npm test
npm run build
```

`dist/index.html` 为可独立托管的静态成品。`.mjs` 须以 JavaScript MIME 提供，不能直接双击 file:// 打开。

## 玩法

- 从 90 金币、一个手洗工位开始。按住精洗按钮或空格，会自动覆盖整车；拖动车身可集中清洗指向的区域。泡沫→冲洗→上蜡自动切换，不要求找最后一个像素。
- 一辆车完成后实际结算一次。亲手参与超过 1 秒加 18% 小费；员工自动作业没有手动小费。车辆会真实排队、进场、清洗、驶离。
- 目标订单累计达成并点击领奖。升级水泵、套餐和招牌，每店最多三条实体车道；每条车道有独立员工与五档设备。第二车道 520、第三车道 1480；首位护理师 250；本店洗满五辆后可买 700 金币的自动滚刷。
- 点击工位、全店视角、护理卡顶端的换道按钮，或键盘 1/2/3，切换作业位置。Q 全景，E 设备，Esc 关闭/暂停。
- 1–5 星按本店累计洗车量 0/5/16/35/70 晋升。四套永久服装有真实模型差异及三维旋转试穿：工装、赛车护目镜/条纹、白色技师外套/耳罩、金边制服/金色喷枪。
- 35 辆/4200 金币开公路店，85 辆/9800 金币开夜光店。之后按商圈延伸，开店费递增。每店设备、员工、车流、订单、星级独立保存，钱包和服装共享。公路/夜光基础售价 +25%/+50%，每个新商圈另加 35%；新店更早出现高价车型。
- 三星可聘 2400 金币驻店店长。离店时，每条有员工或自动设备的车道在线托管产生 0.8 金币/秒起，套餐每级加 0.22；单店积累上限 1200+本店洗车量×5。此收益单独标明，不伪装为完成车辆；暂停/离线不计时。
- 自动保存。管理、暂停、隐藏页面冻结经营，切回来不追补离线时间。`?slot=<名称>` 使用独立档，`?qa=<名称>` 使用测试档，均不会覆盖别的档。

## 文件与素材

`src/` 规则、车辆、场地、特效、UI、输入与音效；`vendor/` 随附 Three.js r186 与 MIT LICENSE；人物、车辆、洗车棚、喷枪、装扮、环境反射、粒子与音效均由代码生成。`assets/ui/` 随附 Tabler MIT 图标、Nunito OFL 字体及许可证，见 `assets/ui/ASSETS.md`。没有使用参考游戏的人物或模型。

`qa/` 包含验收时的原生截图，不是运行依赖。`?metrics=1` 显示当前浏览器渲染数据。

研究截图、用户参考图、下载归档和开发日志不包含在发布包中。实际测试边界见 `QA.md`。
