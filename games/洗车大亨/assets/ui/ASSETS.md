# UI assets · v0.2.0

- Icons: Tabler Icons 3.51.0, MIT, https://tabler.io/icons / https://github.com/tabler/tabler-icons . Selected official outline SVG assets from the npm release. Paths are unchanged; root color is set to `#24495c` for the game palette. License: `TABLER_LICENSE.txt`.
- Font: Nunito variable TTF, SIL Open Font License; https://github.com/googlefonts/nunito . Reused the existing locally bundled licensed font from `games/skyblock-frontier/assets/ui/`, keeping `NUNITO_OFL.txt`. Chinese uses the installed Microsoft YaHei fallback with matching weight hierarchy.
- All runtime files are local. No external icon or font CDN is required.
- The user's reference screenshots guide button weight, typography, spacing and palette; they are not used as backgrounds or texture assets in the game.
