## v0.5 长期经营成长

保留已验收的 v0.4 绿色内墙、红色外墙、暖色拼木、蓝色床品、亮蓝界面与原主楼场景。在原六间房经营之后延伸：

- **永久头衔**：累计营业额达到1,000 / 5,000 / 20,000 / 60,000 / 150,000，依次晋升新晋店长、人气店长、海岛主理人、五星总经理、度假村董事长。花钱不降级；已存营业额直接计入。入口门牌随头衔变化，人气与五星阶段有金星徽记；可选蓝金、白金和皇家紫制服，经典制服默认保留。
- **海景别墅区**：主楼六间海景级 + 泳池 + 咖啡吧后，花6,000修栈桥。四栋别墅建造价3,200 / 4,500 / 6,500 / 9,000，各可升五级；普通房费240 / 340 / 470 / 640 / 860，贵宾1.5倍。主楼保留并继续营业。
- **真实动线**：别墅客人仍在主楼前台办理入住，再沿栈桥步行；专属别墅管家在新区域取布草、清洁。毛巾快捷键前往最近布草间；全景包含两座岛。
- **多档成长**：五位员工、泳池、咖啡吧、步速与托盘分别有五级；培训同一位员工，不额外复制员工。托盘最高16条。房费收集器与服务冲刺各有三级；冲刺持续8秒，冷却40 / 35 / 30秒，加快移动与清洁，暂停冻结计时。
- **重复目标**：累计营业额1,000后有三张经营订单，完成手动领取后替换为不同订单，员工工作同样计入。两栋别墅营业后可重复购买经营研修，每档全店收入加1%，价格递增。订单和目标奖励不计营业额。

右上星形按钮或经营面板“成长”进入。沿用原存档键，无须重新开局。本目录为用户验收后上传的 v0.5.0 源码基线；Loopit 初稿接入要求见 LOOPIT_HANDOFF.md。

## 启动

双击工作区根目录的 **启动海岛酒店.cmd**，或本目录 **启动试玩.cmd**。

也可执行 `python serve.py --open`，打开 http://127.0.0.1:8799/ 。需要Python3提供本地静态服务，以及支持WebGL2的浏览器；不需要npm install。资源随目录提供，没有运行时外部CDN。不要直接双击HTML。

## 经营

- 左下摇杆或WASD/方向键移动。点击地面自动寻路；拖动画面也可连续移动。右侧前台、清洁、毛巾按钮可导航至岗位。
- 在前台内侧停留，自动为排队客人办理入住。客人实际走进空房，住宿后退房；房间变脏，门外留下本次房费。走近钞票自动收款，也可点击顶部资金按钮前往最近收款点。
- 到布草间补充干净毛巾，再到脏房床尾打扫。每次清洁消耗1条，初始最多携带4条，首次升级托盘后8条，继续升级最高16条。清洁中离开可以稍后继续。
- 开局两间营业客房，可扩建至六间。每间可从清新→舒适→海景逐级升级；床品深浅、床架、家具陈设和实际房价一同升级。
- 清洁员会取布草、清洁；接待员会办理入住。一次雇用持续服务，首版没有额外工资扣费。
- 开放泳池后，部分住客会在退房后游泳；需补给泳池毛巾，每次游玩留下28收益。泳池服务员会自动搬运。
- 开放咖啡吧后，部分住客会前去消费。走到吧台内部自动制作饮品，咖啡师可以代劳，每杯留下24收益。
- 十个阶段目标逐步发放一次性奖励，完成后引导到海景别墅与长期成长。客人等候过久会离开，不扣掉已有资金。不是有限闯关或真人联网竞赛。
- Q/右上全景按钮切换镜头，E打开经营，Esc暂停。查看经营面板时世界暂停，关闭后继续。

## 保存与验证

普通存档 `tidelight-hotel-v1` 保存在当前浏览器同源localStorage，保存资金、客房、雇员、目标与客人进度。刷新恢复；本地服务器需保持同一端口。后台/失焦相关暂停与声音按页面逻辑处理；不同浏览器和地址不共享存档。

`?qa=<名称>` 使用独立测试存档。`?showroom=1&qa=visual` 是有明显横幅的美术陈列样板，直接展示扩建外观，不读取或写入经营存档；不作为正常赚取资金的证据。`?showroom=estate&qa=visual`另展示四栋不同级别的别墅，同样明确标注且不读写存档。

`npm test` 执行实际经营、寻路、房费、清洁、员工、暂停和保存等规则测试。`npm run build` 输出自包含dist。浏览器实测范围与不足见 [QA.md](QA.md)。

## 素材与范围

房间、家具、人物、海岛、棕榈、泳池、咖啡吧、纹理与UI为本项目程序生成。声音由Web Audio合成。没有复制参考游戏素材或代码。Three.js r186、RoundedBoxGeometry、BufferGeometryUtils沿用工作区随附MIT版本，许可证见 `vendor/LICENSE`。

原作参考：https://play.google.com/store/apps/details?id=com.master.hotelmaster&hl=en 。本项目是独立浏览器首版，未实现原作全部酒店、活动、付费系统或商业资产质量。本目录保存验收后的完整源码；源码上传、Loopit 草稿和发布分别记录。
