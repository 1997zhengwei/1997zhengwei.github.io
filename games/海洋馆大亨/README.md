# 海洋馆大亨 · 蔚蓝海岸

v0.4.0 已验收源码交付基线。参考 Aquarium Land 的潜水捕鱼与水族店经营循环，以真实 Three.js 三维模型制作。用户于 2026-11-13 授权上传至现有 GitHub games/海洋馆大亨/ 并接入 Loopit 初稿；平台实际结果另行记录。

## v0.4.0 一鱼一缸，扩大原缸

- 六种鱼始终各有一个专属展缸，不再生成重复展缸或新增长廊段。
- 点击鱼缸管理中的「扩建」：原缸会平滑变宽、变高，实际游动空间与水位一同变化；容量每级 +7，售价与客流继续成长。菜单显示本次扩建前后的直径、高度和容量。
- 缸体向外侧生长，中央通道与补货点保持通畅。极高等级横向增幅渐缓，继续增加高度，避免鱼缸相互重叠或挤进道路。
- 兼容 v0.3 存档：同鱼种重复缸合并回原缸，保留总容量、营业库存、稀有库存、最高单缸等级、历史升级投入对应的馆级与原有称号。原来长廊上的玩家及员工安全返回原馆，背包不丢失。迁移重复保存不会再次叠加容量。
- 稀有鱼仍在同种鱼缸里永久留展；已有财富陈列、清蓝海水、玻璃通道与荣誉动画保留。这轮只修改本地。

## v0.3.0 历史记录（重复缸扩建已在 v0.4 取消）

- 原海岸向后延伸珍藏长廊，每次付费增加两个真实展缸，没有预设最后一段。首先开放小丑鱼与蓝吊鱼即可扩建第一段；后续轮换使用六种已开放鱼源，不新增海域或分馆。
- 馆级由累计营业额、扩建和展缸升级共同成长。展缸初始上限 12 级，每 5 个馆级再提高 6 级，每次扩建再提高 2 级；装备上限也逐步提高。高等级价格继续增加。
- 6 种珠光珍稀鱼出现在原鱼群中，具有独立配色、材质与星芒。图鉴可追踪现身的珍稀鱼；首次送回展馆会永久留展，之后同种珍稀鱼进入真实库存，按普通鱼售价的 4 倍出售。助手不会抢捕珍稀鱼。
- 客流随营业展缸、馆级与宣传提升；新增展缸能排队、补货、售卖，自动捕鱼会考虑长廊中的缺货。为控制手机负载，同时实际模拟最多 96 名顾客，后续宣传继续影响到店速度和每单数量。
- 馆长称号依馆级或累计营业额解锁，不因花钱降级。金冠、光芒与彩纸庆典反馈；高阶称号继续累计星级。点击左上角查看实际馆长名片，可手动重播已获得荣誉，不提供虚构在线排名。
- 参考用户新图调整为清蓝海水，减淡过密水纹，保留暖沙地、薄荷绿和原人物；增加可穿行的玻璃观赏廊，立柱纳入寻路碰撞。
- 原展馆旁增加真实三维钞票陈列，随可用余额增减。点击右上角余额近看，不创造额外收入。远处长廊和模型按镜头附近加载并释放。
- 沿用原存档键并兼容旧进度；这轮没有 GitHub 或 Loopit 写入。

## v0.2.0 本轮修正

- 码头改为连续下水坡道。姿态、高度、携带网袋与地形使用同一剖面；在进入实体坡面前完成直立，长脚蹼也会跟随坡度抬起，不再用延迟翻转让身体穿进码头。
- 岸边加入身体安全距离，只从中央坡道上下水。旧档若停在旧岸边无效位置，会移到邻近安全海面，保留金币、鱼和升级。
- 六种鱼重塑体型、眼睛、花纹、鳍条与鳃线，锦鲤增加须、鳐翼起伏、黑鳍鲨区分上下尾鳍；玻璃内的巡游范围按真实模型边界留出余量。
- 潜水员增加完整头套、双镜片护目镜、呼吸器软管、双气瓶、背带、腕表、手套、护膝和专业脚蹼。游客增加帽子、发型、墨镜与条纹服饰。
- 更清亮的青蓝海水、粉紫珊瑚、弧面棕榈叶、海星、沿岸花坛、彩旗与入口拱门；展缸采用更通透的水体与彩色饰边。
- 装备菜单新增「查看装扮」，可近看实际潜水员；展馆与图鉴使用实际三维鱼模型生成的清晰预览。

## 开始试玩

在本目录双击 `启动试玩.cmd`，或：

```powershell
cd games/海洋馆大亨
python serve.py --port 8830
```

打开 http://localhost:8830/ 。需要 Python 3。不要直接双击 HTML；ES modules 需通过本地 HTTP 加载。

```powershell
npm test
npm run build
```

Node.js 仅用于规则检查与静态构建，不需 npm install。`dist/` 是包含同目录字体和依赖的独立可部署版本。

## 怎么玩

1. WASD / 方向键，或拖动摇杆移动。也可拖动画面移动、点击地面前往。
2. 沿中央码头下海，或点“下海捕鱼”自动前往当前需要的鱼群。
3. 靠近鱼群会自动捕捞，圆环蓄满后鱼才入网。空格 / 撒网按钮可短时加快捕捞。
4. 网兜装满后主按钮改为回馆；也可随时点小房子回馆补货。接近对应展缸，鱼会逐条游入。
5. 顾客实际购买、带走库存鱼才结算金币，自动到账。点成长目标领取一次性奖励。
6. 扩建展馆开放新的鱼种。升级装备、展缸或雇潜水助手提高效率。

点击展缸标签进入管理，“近看鱼群”切换观赏镜头，拖动环顾、滚轮缩放，左上角返回经营。观赏与打开经营面板时业务暂停，鱼的展示动画继续。

## 库存、氧气与存档

初始只有小丑鱼展缸，内有 3 条可售库存。鱼源捕获后需重新生成，网兜与展缸有实际容量限制；满缸不会吞掉多余携带的鱼。

初始氧气 60 秒，回岸自动补满；耗尽会自动带着全部收获回到码头，不扣钱或丢鱼。更大的气瓶增加潜水时长。

存档键 `aqua-coast-save-v1`，设置键 `aqua-coast-settings-v1`。资金、鱼、展缸、升级、已领目标、顾客和助手保存到当前浏览器。不同域名/端口存档独立。后台、暂停、关闭不增加离线收益。问号手册内可二次确认后重新开始，仅重置本作。
