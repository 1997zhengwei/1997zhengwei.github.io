## 平台适配差异与边界

- 实际游戏页面没有额外 iframe 包壳，使用平台自己的 JS/CSS 产物。Loopit 编辑器自身用预览 iframe 展示产物，这是编辑器界面结构。
- 本地/GitHub 版本依赖全部同目录保存。Loopit 宿主额外注入 react-stack、monitor、Tone、QRCode 以及 Loopit runtime 等公共 CDN 脚本；平台回复宿主配置锁定。不能把平台版本称为完全离线版。
- 平台声称保留 66 个源文件，本轮没有独立导出全部平台文件核对哈希，也未独立核对构建 target，因此不声称平台与 GitHub 字节级一致。已通过真实画面、经营数值、八设施菜单、原有操作规则和完整乘坐核验代表性接入效果。
- 平台本轮完整乘坐覆盖旋转杯和过山车，其余设施已确认菜单和模型存在，未逐项重跑全部长线经营。真实手机设备性能、主观音效以及账号跨设备云存档不在本轮验收范围；游戏使用当前浏览器存档。
- 未添加 Power、翻译或新玩法；后续先在此草稿迭代，正式发布另行处理。
