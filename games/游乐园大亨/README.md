# 欢乐岛 · 游乐园大亨

源码交付基线 **v0.3.2**。真实 Three.js 三维园区，中文界面，兼容桌面和手机触控。

## 运行

需要 Python 3；Node.js 仅用于构建和规则检查。

```powershell
cd games/游乐园大亨
python serve.py --port 8820
```

浏览器打开 `http://127.0.0.1:8820/`。不要直接双击 HTML：浏览器需要通过本地 HTTP 加载 ES modules。

```powershell
npm test
npm run build
```

`dist/` 是包含源码、字体与依赖的独立静态构建，无运行时 CDN、账号或网络接口依赖。本目录为用户认可的 v0.3.2 源码交付基线，位于 games/游乐园大亨/；Loopit 首稿要求与后续修改约束见 LOOPIT_HANDOFF.md，实际平台结果另行记录。

## 现在可以玩什么

- 从 850 金币和已开张的旋转木马开始。首批 8 位游客已免费入园排队，后续客人从大门进来，每人入园费 6 金币。
- 建造海盗船、摩天轮、过山车和两翼四个新设施，观看游客选择设施、排队、上客、乘坐、离场。完成乘坐后才结算设施收入。
- 升级设施提高票价与吸引力，每升两级开放更多已有座位，直到座位全开。主岛四种设施分别有 12／10／16／12 个真实乘坐位置，两翼容量见上表。
- 升级入口增加客流和人数上限，增加运营员工缩短等候发车时间，改善花园提高耐心。冰淇淋屋开放后，游客实际走到店前消费，再离园。
- 完成十项里程碑领取一次性奖励。每座设施可升至 20 级，四类园区服务可升至 8 级。
- 八座设施均能免费亲自试乘，未建成的蓝图也可以先体验。试乘暂停经营，不扣费、不结算虚拟乘坐收益；退出后继续原来的游客与运行进度。
- 切换日景／夜景。至少四座设施建成后，夜晚会出现海岸烟火。

## 乘坐与操作

| 操作 | 桌面 | 手机 |
| --- | --- | --- |
| 浏览园区 | 鼠标拖动 | 单指拖动 |
| 缩放 | 滚轮、加减按钮 | 双指缩放、加减按钮 |
| 旋转视角 | 左右旋转按钮、Q／E | 左右旋转按钮 |
| 管理设施 | 点击设施或名称标签 | 点击设施或名称标签 |
| 亲自乘坐 | 设施详情／建造菜单中的乘坐按钮 | 同左 |
| 乘坐时转头 | 在画面内拖动 | 单指拖动 |
| 举手 | 按钮、空格 | 按钮 |
| 视角 | 乘坐／跟拍，舒适／动感 | 同左 |
| 返回 | 返回经营、Esc | 返回经营 |

旋转木马有起步、减速和木马上下起伏；海盗船逐渐加大摆幅，再平稳收回；摩天轮吊舱始终保持水平；三节过山车列车共用轨道姿态和弧长路径，爬升缓慢、下坡加速、回站减速。所有速度仪表来自对应设施的运动参数。

## 存档

自动保存到当前浏览器的 `localStorage`，包括资金、设施、服务、已领取目标、游客位置、队列和正在运行的批次。后台和关闭页面不产生离线收益。返回后继续运行，避免重复结算。

通过右侧问号进入园长手册，可确认后重新开始。不同域名／端口的浏览器存档独立。

## 首版范围

当前是一座扩建海岛、八座设施和预设建设地块。没有自由绘制轨道、任意移动建筑、多园区或联网排行。真实手机设备性能与主观听感还需要用户试玩；模拟手机视口的验收记录在 `QA.md`。
