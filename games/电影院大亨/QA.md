# 星映影城 v0.4.0 经营流程验收

2026-11-13。本轮按用户反馈处理六片画面重复、观影干扰经营和空厅扩容难操作。保持原有影院布局、配色、客人、定价和成长节奏，本地验收后，用户于 2026-11-13 授权 GitHub 中文目录和 Loopit 初稿。

## 本轮行为

- 六个影片 ID 和原有授权、排片继续保留。后三部更新为《珊瑚奇遇》《逐日飞车》《雪境来信》，各有新的原创人物、世界、独立图片和字幕。海底气泡、云端速度线与飘雪匹配新主题。素材原图及完整内置 image_gen 提示词见 [ASSETS_V040.md](ASSETS_V040.md)。
- 主界面情境按钮优先补货、清洁和经营；影厅列表不再推观影，开场提示也不再邀请观影。详情底部保留一个可选入口，收入和升级不要求进入观影视角。
- 空厅立即扩容。有已购票观众时可以一键预约：预付一次金币，自动停票，当前观众完整看完并离开，由改造团队自动清洁、施工三秒，完成后恢复营业。其他影厅照常营业。
- 预约成功自动收起菜单继续经营，不要求玩家守在门口。预约可取消，全额退款不计入收入。一个厅同一时间只有一份预约，刷新后继续，完工不再扣款。
- 普通未预约的散场清洁仍由经理或保洁员完成。营业菜单沿用原有暂停规则，关闭后继续营业与改造。

## 原生浏览器复核

开发测试使用独立的 `127.0.0.1:8842` QA 存档，用户使用 `localhost:8842`。没有清空或替用户购买。

1. 载入已有五厅、首厅 36 座、三类员工的自然经营 QA 存档，原资金和影片保留。第二厅已有 10/12 位预订，仍可点击「预约 · 225」。菜单自动关闭，主界面显示预约。
2. 进入预约详情，出现「已预付 225」与取消入口，扩容按钮禁用以防重复。取消后出现全额退款提示、预约消失；随后正常再次预约，刷新后仍保留，不再次收费。
3. 经理没有去第二厅守候。继续经营后，第二厅自动扩至 16 座；详情显示 LEVEL 2、16→20、下一次费用 305，营业按钮为「暂停售票」，表明已恢复接待。其他厅在此期间继续售票放映、资金自然增长。
4. 片库六张图片全部实际加载，文件地址和内容各不相同。用 QA 自然经营所得购买《珊瑚奇遇》和《逐日飞车》，原先三部仍拥有；第三部新片受原有解锁/资金条件约束，没有注入资金绕过。
5. 将《珊瑚奇遇》排入空闲的第四厅，当前与下场均正确更新。进入仅作验证的可选入口，银幕实际显示海底新画面，之后返回经营。该厅随后正常进入 12/12 放映。
6. 390×844 片库和 320×740 影厅详情无横向溢出。320 窄屏内三列按钮均为 70×44，菜单可滚动，观影入口仅位于详情底部。
