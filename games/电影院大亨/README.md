# 电影院大亨 · 星映影城

v0.4.0 用户验收源码基线。2026-11-13 用户授权上传到现有公开仓库 `games/电影院大亨/`，并同步一版中文 Loopit 可编辑初稿。平台是否生成、实测和发布分开记录，不把源码上传视为平台已经接入。

## 开始运行

本目录双击 `打开游戏.cmd`，或运行 `python launch.py`。也可 `python serve.py --port 8842`。请通过 HTTP 服务打开，不直接双击 HTML。

无需 npm install；Three.js r186、Nunito 字体和六张原创电影画面随包。Python 用于静态服务，Node 用于可选检查与构建：

```powershell
cd games/电影院大亨
npm test
npm run build
python serve.py --port 8842
```

## 已验收玩法

- 经营经理以 WASD、方向键、点击地面或手机摇杆移动，脚下光环和名牌标记主角。售票、爆米花生产/搬运/补货、真实消费、入座、放映、散场与清洁构成持续经营循环。
- 六座独立 3D 影厅，每厅 12→16→20→24→30→36 座，真实模型随扩容增长；紫墙、灰紫棋盘地面、独立白背板银幕、侧走道、滑门和金色厅号。24 种成年比例顾客与独立制服员工，高堆爆米花和交易钞票反馈。
- 六部独立原创影片：《星月列车》《海岛飞翼》《雨夜猫探》《珊瑚奇遇》《逐日飞车》《雪境来信》。排片保留当前顾客的电影，下场才切换；热映需求每三分钟变化。
- 有观众也能一键预约座椅扩容：预付一次、自动停票、完整播完本场、自动整理、施工三秒并恢复营业；其他影厅照常经营，可取消全额退款，刷新后续行。空厅立即扩容。
- 三类真实员工、持续设施升级、三台电玩、资金账本、任务和六档经营荣誉。只有真实服务、消费与完整放映才产生收入，没有假排行或离线刷钱。
- 观影仅在影厅详情底部作为可选入口，主界面优先经营。默认静音，主动开启后使用本地合成音效；无需进入观影才能赚钱。
- 存档键 `starlight-cinema-v1`，保留旧版授权、排片与布局迁移。菜单/暂停/后台停止经营。不同平台域名独立存档，不携带本机玩家数据。

## 源码与 Loopit 接入

`index.html` + `src/` 为维护源码；`LOOPIT_SINGLE.html` 为同源码的合并接入入口，必须保留同级 `vendor/` 和 `assets/`。它直接运行本作三维代码，不是 iframe 或外链演示。

先读 [LOOPIT_HANDOFF.md](LOOPIT_HANDOFF.md)、[单入口说明](PLATFORM_BUNDLE.md) 及 [SOURCE_FILES.json](SOURCE_FILES.json)。包不包含缓存、进程/端口记录、开发机存档、日志或历史 ZIP。GitHub 版本用提交追踪，不新建平行成品目录。
