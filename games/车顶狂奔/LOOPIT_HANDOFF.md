# 车顶狂奔 · CONVOY LEAP — Loopit 源码接入

用户已认可 v0.4.2，授权上传并同步一版 Loopit 初稿。保留中文界面；这是已有完整游戏的接入，不是重新生成简化版。只创建草稿，不发布或送审。

## 来源与运行

- 仓库：`1997zhengwei/1997zhengwei.github.io`，既有游戏分支 `codex/krabby-patty-flip`。
- 子目录：`games/车顶狂奔/`。提交时提供的固定 commit 是接入基准，不导入根部个人网站和其他游戏。
- 原生 HTML + ES modules，入口 `index.html`，主模块 `src/app.mjs`。Node 18+ 运行 `npm run build`，输出 `dist/index.html`，不需要 npm install、远程 CDN、Python 或服务器接口。`serve.py` 只是本地试玩便利工具。
- 首选直接部署此静态 dist/，保持 src/vendor/assets 相对层级和 HTML importmap。不要用 iframe、localhost 或外链替代源码接入。
- 若必须用宿主 React/Vite：将原 src/vendor/assets 作为静态资源保留到 public/convoy-leap/，宿主提供原入口中的 canvas#world（tabindex=0）、div#ui、div#loading，加载原 style.css 和 importmap，再以原生 module 导入 app.mjs。注意 import.meta.url 与裸 three 映射，不要把程序几何改成占位方块或复用屋顶跑酷人物。

## 文件与素材

- `src/simulation.mjs`：真实移动卡车、碰撞、跳跃与慢动作；固定 120Hz 模拟及渲染插值在 app.mjs。
- `src/courses.mjs`：3 张地图 × 3 路段；`progress.mjs`：独立通关记录。
- `scene.mjs`、`truck-model.mjs`、`landscape.mjs`、`materials.mjs`、`finish.mjs`：当前车辆、地图、照明、程序纹理、镜头与后处理。
- `courier.mjs`、`jump-pose.mjs`：新「越隙领航员 07」、手套/腕表及收腿跳跃，人物几何由代码生成。
- 必需的运行数据 `assets/courier-rig.json`、`assets/motion-clips.json`；骨架/动作 CC0，人物/装备代码新创作，来源详见 `assets/ATTRIBUTION.md` 及许可证。
- Three.js r186 和相关依赖随 vendor/ 提供并保留 MIT 许可证。历史 runner.glb 仅供旧基线测试，游戏及生产 build 不加载。
- `qa/` 是开发验证资料，含明确标识的 UI/动作样本；不要把样本入口设成游戏入口，不打包到生产 dist。

## 必须保留的体验

1. 初屏直接选择「日光沙海／赤岩悬桥／极地追风」。选图后展示三个路段，明确“全部通过三个路段，即完成本地图”。推荐本地图首个未通过路段，可重玩已通过段。
2. 三维车顶跑酷，在实际移动的车厢上助跑和换车；碰地/撞障碍失败。白色终点平台必须真正起跳落上。没有虚构对手或排名。
3. 每图 3 段各存最高星级和最佳用时。一星也算通过；所有三段都通过才显示地图通关，返回选图，不自动切下一地图。失败只重试本段。
4. 星级：到终点 / 至少换车 3 次 / 达到该段目标时间。只记实际换到另一辆车的着陆，不让原地跳刷次数。
5. 第一人称默认，V/界面按钮切第三人称。保留镜头相对移动、空中修正、短按/按住略不同的跳高、0.13s 离边宽限、0.16s 起跳缓冲、真实着陆反馈。
6. 手机右下「跳跃」和「慢动作」始终显示；左侧摇杆自动识别触屏，也能手动显示/隐藏。隐藏摇杆不能隐藏跳跃。保留 400×580 竖屏及横屏布局、安全区、指针取消/失去捕获与暂停清理。
7. 下蹲确实能过限高架，普通路段隐藏按钮；相关限高架前 85 米出现，经过后收起。触摸仍按住时不提前隐藏；提示用途。键盘 C 保留。
8. 新人物与头盔、机械背架、护具、缓冲靴、能量腕表；菜单「角色」能转动查看，返回保留所选图/段。腾空双膝向前，双脚前后错位，逐渐伸腿准备落地，不能恢复旧张腿跳。
9. 慢动作约满能量维持 3.6 秒现实时间，世界 0.38 倍速，同时影响车辆和玩家；换车补能，松开缓慢恢复。保留腕表/背架能量反馈。
10. WASD/方向键、空格、Shift、C、V、R、Esc/P 和触屏入口；暂停/失焦冻结物理与计时，重试重置瞬时状态但保留历史成绩/设置。保留高清/流畅、静音和首次交互后的合成音效。
