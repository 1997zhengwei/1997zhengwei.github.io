## 运行

双击本目录的 **启动试玩.cmd**，或工作区根目录的 **启动车顶狂奔.cmd**。也可以在本目录运行：

```powershell
python serve.py --open
```

地址：http://127.0.0.1:8798/ 。需要 Python 3 和支持 WebGL2 的现代浏览器。若端口被其他服务使用，运行 `python serve.py --port 8799 --open`。

不用 npm install。Three.js、人体与动作数据均已随目录提供，运行时无需远程 CDN。请通过 HTTP 服务打开，不要直接双击 HTML。

## 操作

| 操作 | 桌面 | 触屏 |
| --- | --- | --- |
| 前后左右 | WASD / 方向键 | 左下摇杆 |
| 起跳 | 空格；短按和按住的高度略有区别 | 右下起跳按钮 |
| 看向 | 拖动画面 / Q、E | 在画面上拖动 |
| 慢动作 | 按住 Shift | 按住右侧慢动作 |
| 下蹲 | 按住 C | 按住下蹲 |
| 第一/第三人称 | V | 左上视角按钮 |
| 镜头朝前 | 左上朝前按钮 | 同左 |
| 连续前进 | 左上连续前进按钮，再点停止 | 同左；可专注换车和起跳 |
| 屏幕摇杆 | 左上显示摇杆 / 隐藏摇杆 | 自动显示，也可手动切换；跳跃按钮始终保留 |
| 重试 | R；失败后空格 | 结果页马上重来 |
| 通关后继续 | 空格前往剩余路段；地图完成后返回选图 | 结果页主按钮 |
| 暂停 | Esc / P | 右上暂停 |

沿车顶助跑，接近车头再起跳。空中仍可以调整方向或减速。薄荷色四角标记是根据当前速度预测的可落车顶位置，不保证后续车辆不会刹车、转向或碰撞。起跳继承实际支撑点的车速，弯道不反转左右。

## 规则

- 有效落到另一辆车，才计成功换车。原地跳不刷换车次数；连续落车有连跳提示，漂亮换车补充慢动作能量。
- 慢动作满能量约可维持 3.6 秒现实时间，世界以 0.38 倍速度推进；车辆和玩家一起变慢。松开后缓慢恢复，避免无限冻结。
- 车头驾驶室比车厢低，步行过去会短暂落下。离边宽限 0.13 秒，起跳缓冲 0.16 秒；着陆按角色脚部半径留出少量边缘容错。
- 车辆会跟随弯道、避让分流柱、刹车和相互挤碰；撞柱会停下，少量车辆受摆锤撞击会倾覆。它们是移动平台，没有虚构对手排名。
- 前方白色终点平台需要起跳落上；车队自身会在断路处掉落。终点红色标识可在远处看见。
- 3 星目标：到达终点 / 至少成功换车 3 次 / 在本路段目标时间内完成。奖励不重复结算，保存历史最高星级与最快用时。
- 任意星级的有效通关都算通过该路段；三个路段全部通过才完成本地图。进度可跨局累计，失败只需重试本段。单独通过第三段不会跳过前两段或自动转到别的地图。
- 失败重试保留本路段的初始配置；改变路线、起跳时机和慢动作时机，会改变后续经过车流和机关的时间。
- 暂停、切到其他页面、窗口失焦时冻结物理和计时；声音随状态淡出。可切高清/流畅；浏览器后台降帧不作为实际前台难度测量。
- `?qa=1` 使用独立 QA 存档，显示调试读数，不改普通试玩的成绩与地图选择。
