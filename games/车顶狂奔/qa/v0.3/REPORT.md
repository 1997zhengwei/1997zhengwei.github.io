# v0.3.0 · 地图选择与三段通关

日期：2026-11-11。本地正常入口：http://127.0.0.1:8798/?v=0.3.0 。

## 本次行为

- 首屏直接呈现「日光沙海」「赤岩悬桥」「极地追风」三张地图及各自已通过路段数。
- 选择地图后进入三个路段的说明页，明确提示「通过全部 3 个路段，即完成本地图」。默认选中首个未通过路段，可自由选段重玩。
- HUD 标识当前路段，例如「路段 3 / 3」。失败仅重试当前路段，三个路段分别保存成绩。
- 通过一段后显示本地图各路段状态并引导去剩余路段。必须三个路段都有真实获胜记录，才显示「地图通关」。全部通过后返回选图，不自动开始下一张地图。
- 继续沿用正式存档键。进入选图页时，空格或 R 不会跳过选图直接开始旧地图。

## 实际浏览器操作

Codex 内置 Chromium，1280×720 桌面与 400×580 iframe。使用独立 `qa=map-flow-v03`、`qa=map-flow-v03-mobile` 测试存档。

- 首次进入三个地图按钮均可见；空格、R 不会开局。选赤岩悬桥后可见规则、0/3 与三个路段，选第三段并开始，HUD 实际显示「路段 3 / 3」，可暂停。
- 从暂停返回地图选择；刷新后仍首先呈现三张地图，没有直接进入旧地图。
- 手机视口实际选择极地追风、查看说明、开始第一段并暂停；三张地图、规则、三个路段与开始按钮没有裁切。
- 日光沙海实际助跑、跳跃和换车，最终落地失败。点击「马上重来」，地图和路段保持一致，计时/换车计数归零，可重新开始。不将这次失败写成实际通关。
- 正常入口读取到原有日光沙海首段三星，首页显示已通过 1/3；选择该图默认推荐第二段，第一段三星仍在。没有重置原成绩或复制 QA 样本到正式存档。
