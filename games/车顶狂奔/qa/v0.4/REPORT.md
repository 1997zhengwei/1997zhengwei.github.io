# v0.4.0 · 屏幕跳跃与独立人物

日期：2026-11-11。本地试玩 http://127.0.0.1:8798/?v=0.4.0 。

## 修改

旧版使用屏幕宽度与主指针媒体查询控制整个触屏区的显示。这次让跳跃、慢动作和下蹲按钮在所有游戏视口始终存在，不再由设备检测隐藏；触屏识别只决定是否默认显示摇杆。识别覆盖窄视口、触点数量、主指针与任意指针粗精度，另有手动显示/隐藏摇杆入口。补上多指归属、取消、失去捕获和暂停清理，避免触摸中断后按键粘住。三地图/三路段的规则和旧存档键保留。

「越隙领航员 07」使用独立制作的可见几何：头盔、曲面风镜、胸甲、飞行夹克、护膝、手套、靴子、机械背架、线盘与能量腕表。运行时没有加载屋顶跑酷的旧人物网格、脸、头发或衣鞋。CC0 动作骨架与已有跑跳动作继续沿用，许可证有明确记录。第一人称使用新手套和腕表，慢动作能量变化对应腕表和背架灯格；陀螺环在慢动作期间转动加快。

人物由 71 个合并网格、约 32,700 个三角面构成，完整人物只在第三人称及角色预览显示。这是几何预算记录，不是对真实手机帧率的承诺。

## 自动验证

`npm test`：35 项通过。原有 28 项规则/运动/地图进度检查保留，新增检查：

- 横屏手机、平板、触屏混合设备的布局判断；屏幕跳跃输入进入真实物理并升空。
- 指针归属、取消、失去捕获、暂停清理与下一次触摸恢复；暂停期间不接受移动/跳跃。
- 新人物鞋底高度、整体尺寸、网格预算；待机/跑/跳/落地/下蹲动作全部绑定到有效骨骼，变换没有非有限值。
- 第一人称与背架能量显示随可用能量变化。

## 实际浏览器操作

Codex 内置 Chromium；独立测试存档 `qa=crew-v04`、`qa=crew-v04-mobile`，不写入正式玩家的测试成绩。`mobile.html` 只改变 iframe 真实尺寸，里面运行完整游戏，没有修改角色坐标、获胜状态或能量值。

- 400×580 竖屏实际点击橙色「跳跃」，可见状态从车顶高度约 3.82 升至 y=6.29、状态 air；右下按钮尺寸 90×90。左右控制区与提示不遮住中央落点。
- 手动隐藏摇杆后，跳跃仍显示为 flex、尺寸 90×90，实际再次跃起至 y=6.22；随后可恢复摇杆。
- 844×390 横屏实际点击跳跃，y=6.15、状态 air；摇杆、跳跃、慢动作、下蹲和 HUD 均可见。
- 1024×600 平板视口按住屏幕慢动作 1.1 秒，能量条实际从满格变到 69.3644%；随后点击跳跃，y=6.42、状态 air。慢动作按钮可点击高度为 44px。
- 第一/第三人称切换；新人物在实际跳跃中摆出跳跃姿态。菜单人物正面、背面、手机完整入镜与转动均检查。
- 在赤岩悬桥第三段进入角色预览，再返回，仍显示「开始路段 3 / 3」，没有丢掉所选地图/路段。
- 过程中实际暂停和重试可用。没有把几次起跳检查记成整段通关，也没有新造测试成绩。
