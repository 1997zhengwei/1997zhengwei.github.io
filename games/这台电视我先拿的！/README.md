# 《这台电视我先拿的！》v2 · 疯抢修正版

手机竖屏的 3D 黑五抢购小游戏。60 秒内推着购物车抢打折货、推过绿线结账，和三位抢购大妈比谁省得多。

## 本地启动

使用 Node.js 22 或更新版本，在含有 `server.mjs` 的目录运行 `node server.mjs`，访问 http://127.0.0.1:8994/ 。无需安装 npm 依赖，也可以用静态服务器托管整个文件夹。点击绿色按钮开始，或直接从按钮拖动起跑。手机单指拖动，电脑用 WASD 或方向键移动、空格冲刺。

## 玩法

- **推车叠叠乐**：货在车里一层层往上摞，最多 8 件（升级车筐可到 16 件）。摞得越高，急转弯越晃，超过临界就"哗啦"倒一地。
- **掉在地上的货谁都能捡**：翻车、撞车掉出来的商品会在地上闪十几秒，大妈们也会冲过来抢。
- **连抢**：2.8 秒内接着抢到下一件，倍率 ×1.25、×1.5……最高 ×2。加成随商品结账，掉货会清除该件的加成。
- **冲刺撞车**：右下角"冲！"（空格），撞到对手会把她车顶的货撞飞。大妈看到你满车也会冲过来撞你。防掉货绑带可以抵消。
- **闪购警报**：开局、20 秒、40 秒三波，全场红灯加广播"限时 1 折"。
- **关门大甩卖**：最后 10 秒结账金额翻倍。
- **结账表演**：商品一件件飞上收银台扫码，音调一件比一件高，最后盖章"省 ¥xxxx！"。
- **每局购物清单**：3 件指定商品，买齐（结账带回）奖励 ¥300。
- **三星**：拿第 1 名 / 买齐清单 / 省到本图目标。每张图的最佳星数会记住。

10 张地图、升级券（每省 ¥250 一张）和商品图鉴都保留。

## 文件分工

- `rules.js` 纯逻辑：移动、货堆倾斜与翻车、地上散货、连抢、冲刺撞车、清单、关门翻倍、对手 AI。可在 Node 里跑测试机器人。
- `market.js` / `layouts.js` 地图、商品、收银点、碰撞与寻路；`market.js` 里的 `targets` 是每张图的三星目标。
- `upgrades.js` 升级数值与升级券。
- `art.js` 购物车、商品、促销贴纸和 3D 顾客（你 + 三位大妈）；`store.js` 卖场场景。
- `game.js` 画面、HUD、演出；`audio.js` 合成音效与背景乐（关门前 10 秒提速）。
- `vendor/` 内置 Three.js 和许可证。

记录保存在浏览器 localStorage（`rushmart.*`）。未标记的早期存档按原倍率保留余额、已购升级和兑换进度，迁移后每实省 ¥250 发一张新券。若当前站点一直使用迁移前的 v2 疯抢版，可以带 `?wallet=v2` 首次打开，按 v2 原倍率迁移同一站点的存档。

本作参考同类卖场抢购小游戏的玩法类型，场景、角色、界面与音效均为原创。
