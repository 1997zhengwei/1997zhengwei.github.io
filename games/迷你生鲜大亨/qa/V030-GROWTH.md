# v0.3.0 成长、装扮与连锁经营

日期：2026-11-12。本地源码版本；未上传 GitHub / Loopit。

## 范围

按用户选定的 1、3、4 实现五星成长、外观升级、特色门店，并扩充顾客。没有加入大订单系统。保留 v0.2 高堆搬货、原店配色与 fresh-mart-v1 存档。

## 已执行验证

- `npm test`：38 项全部通过。新增覆盖旧存档迁移、升星条件和奖励仅领取一次、四星花卉解锁、实际支付后才计花卉销量、装扮收费及能力不变、各店物品与营业款隔离、三店序列化、分红上限与领取。
- 三家店分别模拟 600 秒经营，各种商品均被员工实际生产、补货并成交，包括分店新配方与花束；所有采收、投料、补货、收银点路径可达。
- 24 种顾客设定、48 套造型及全部服装可构造、运动、释放；三店商品、全部托盘几何为有限数值。七类货品 6/14/22 件高堆在 400×580、320×580 投影不盖目标卡。
- `npm run build` 完成，所有模块语法检查通过，dist 为自包含静态版本。
- 真实 IAB 浏览器用明确标注不存档的样例操作：领取四星，开放花卉；购买 7,800 金币礼服、6,500 金币托盘、3,500 金币装修并使用，金额逐笔正确。服装 3D 预览在手机尺寸居中且能完整显示。
- 从五星街角店花 4,000 金币开海滨店，钱包 35,000→31,000；新店营业款为 0，实际采收 14 个芒果、补货、收银后产生 196 营业款。返回街角店保留五星和原先 170 营业款，没有串店，也没有重复开店费用。
- 夜市实际画面核对柠檬、蘑菇、豆浆、菌菇串、花束、灯笼和蓝色街区。320×580 与 400×580 检查管理/装扮/成长面板，320 屏幕文档宽度为 320，无横向溢出；全店视角包含花卉扩建。
- 上述有效试玩页无 error/warn 日志。修复了提袋模型缺少几何辅助函数、预览窗口缩窄后画布裁切、收银款串店、超额配送原料被自然生长回落上限等问题。
- 最后重载正常试玩页迁移旧存档：原钱包 500、待领营业款 23,658、14/14 番茄货堆、5 种已开商品的陈列等级及三位 Lv.1 员工均保留。新星级从一星开始，可依据已完成旧进度领取二星；未代领星级奖励。后续画面显示正常营业款已入钱包。保留正常试玩页，关闭不存档测试页。

## 边界

浏览器手机视口测试不等于真机 GPU 性能测量。目标时间、门店价格与装扮价格是本轮设计值，仍待用户连续试玩调节；没有真实留存或收入数据。托管分红是明确标注的固定在线奖励，不伪造商品销量，不提供离线收益。
