# 黑五最后一单（v4 无尽营业）

黑五夜里你是收银员，顾客源源不断地进店，越来越多、越来越急。分数就是「今日成交额」，看你一晚能卖多少。顾客等不及摔手走人记 1 个差评，3 个差评店长喊打烊，一局结束。新手一局约 3 分钟，熟手约 5 分钟。

关卡版（6 班、三星）保留在 `games/last-checkout-v3`。

## 玩法
- **找条码**：没有文字提示，要看 3D 商品本身。条码朝你时，把商品拖过红线；条码在右侧就点商品右半边（或向左滑），看不到就点左半边。也可以用 ↺ ↻ 和「扫码」按钮。
- **连扫**：扫码的嘀声连起来是一段循环小调，扫得越顺越像在弹琴；连扫让顾客消气。扫错会断连。
- **爆单时间**：成功扫 12 件攒满「爆单槽」，进入 7 秒爆单时间：一波闪购顾客涌进来（每人 2 件），条码全部朝你、贴纸自动撕、顾客秒付款、所有人耐心冻结，每扫一件额外 +¥10 并飞金币，小费翻倍；收银台光束变彩虹，全队跟着节拍蹦、举手挥舞。
- **店长点赞**：成交额每破一个里程碑，自动抵消 1 个差评。
- **搞怪商品**：捏捏小黄鸭（扫码「嘎！」）和冷冻大火鸡（扫码「咚！」）。开心离店的顾客会跳起来转一圈。
- **小费**：结账时顾客开心给实付的 20%，一般给 8%，不爽不给；爆单时间里翻倍。成交额 = 实付 + 小费 + 爆单金币。
- **黑五贴纸**（第 6 位顾客起）：黄色爆炸贴要先点掉再扫。漏点就是多收钱，顾客当场炸毛、耐心大跌、不给小费。
- **找零**（第 3 位顾客起）：现金顾客显示「收 ¥100 · 找零 ¥17」，点 50/20/10/5/1 凑出正好的数，超了清零重凑。
- **客流爬坡**：每进店 5 位顾客升一级「客流 Lv」。顾客来得更快（约 7.2 秒→2.4 秒一位）、买得更多（2–3 件→3–5 件）、更没耐心，条码更多藏在侧面和背面。每第 10 位是 5–6 件的大单顾客。
- **里程碑**：成交额破 ¥500、1000、2000、3000、5000… 时弹横幅、撒花。
- **称号**：实习收银员 → 熟练（¥1500）→ 金牌（¥3500）→ 爆单（¥7000）→ 收银之神（¥16000）。
- 打烊时打印一张小票：营业时长、接待人数、开心离店人数、小费、帮顾客省、最高连扫、三条差评记录、今日成交额和历史最高，最后盖称号章。点小票可跳过打印。

## 文件
- `rules.mjs`：纯规则。`startRun(seed)`、`tick`、`turn/peel/scan/payCard/giveChange`；`difficulty(n)` 决定第 n 位顾客的难度。
- `balance.mjs`：`node balance.mjs [局数]`，新手、熟练、高手三种机器人各跑 N 局，输出局长、成交额、接待人数、差评来源、称号分布。当前（150 局中位数）：新手 197 秒 ¥4526；熟练 287 秒 ¥10721；高手 381 秒 ¥20582。人潮最终会淹没所有人，不会无限玩下去。
- `stage.mjs`：Three.js 超市、收银台、传送带（当前件 + 下一件）；顾客从店门口进来、蛇形排队，开心从右边离开、生气从左边离开。顾客是 8 套 Q 版购物人：脸是画在头部球面贴片上的贴图（大眼高光、睫毛、眉毛、腮红、雀斑/痣，开心/一般/生气三张），发型用贴头皮的发片生成（一绺一绺的刘海、波波头、长发、丸子头、马尾、爆炸头、毛线帽、棒球帽），穿搭有卫衣、羽绒服、毛衣+围巾、开衫、连衣裙、T 恤，手里拎黑五购物袋、挎包或购物篮。相邻顾客不会撞造型。
- `qa-people.html`：顾客近景检查页，`?row=0/1` 看两排各 4 位，`?mood=2` 换表情，`?spin` 转圈看背面。
- `game.mjs`：触屏手势、成交额滚动大屏、差评灯、钱箱、飘字、横幅、撒花、打烊小票、存档（localStorage `last-checkout-v4`：最高成交额、最多接待、局数）。`?dev` 时用独立存档并暴露 `window.__lc`。
- `audio.mjs`：程序化音效和背景音乐；排队到 4 人或只剩最后一个差评时切到快节奏。静音键 `last-checkout-v1-muted`。

## 本地运行
在本目录运行 `python -m http.server 9225 --bind 127.0.0.1`，打开 `http://127.0.0.1:9225/`。Three.js 随源码打包；标题字体从 Google Fonts 加载，离线时退回系统字体。

键盘：← → 转面，空格扫码，S 撕贴纸，回车刷卡，数字 1–5 依次点 50/20/10/5/1。
