# 黑五福袋（v4）

黑五活动一袋统一实付 ¥99。把商品装进纸袋，完好商品的原价总和达到过关线就能结账，装得越值星越多。共九关，通关解锁下一袋。浏览器保存每关的最高原价和最高星级。

旧存档只有最高原价时，首次加载会按 v3 和 v4 各算一次，保留较高的星级。之后每局按 v4 门槛结算，并记录历史最高星级。

## 玩法
- 点商品后按「旋转」可以横放，再拖进纸袋；也可以先点商品，再点袋内的列。绿色预览表示能放，红色表示装不下或会压坏易碎品。重物尽量垫底。
- 拖回柜台可以换摆法，「撤回」恢复上一步。
- **第 1 关是教学**，所有商品都装得下。**从第 2 关起，柜台上的商品总格数是袋子容量的 110%–125%**，必须挑「每格最值钱」的装。柜台里混着「巨型抱枕」「零食大礼包」「巧克力大盒」这类占地大、单价低的陷阱货。
- 后六关有斜肩、抬底、窄口、双仓、侧兜和组合袋型，商品必须整个落在袋型范围内；横跨隔板的商品要高于隔板。画面上的空格数包括商品底下留出的空隙，可用落点预览查看能不能塞进去。
- 电脑键盘：选中商品后用左右方向键调落点，R 旋转，回车放入，Ctrl+Z 撤回。

## 结账开袋
结账后商品按价格从高到低一件件弹出，价值滚动累加，然后抽一份「福袋惊喜」赠品：袋子装满 95% 以上抽大奖，85% 以上抽中奖，否则小奖。赠品只算进「到手价值」和「赚了几倍」，不影响过关和星级。最后是星级和「省 ¥xxx」印章；点弹窗任意处可以跳过演出。

## 文件
- `packing.mjs`：商品、关卡、落位与承重规则（纯逻辑）。
- `stage.mjs` / `merch.mjs`：Three.js 纸袋和商品模型；袋型轮廓带缝线，提手挂倒「福」字吊牌。
- `game.mjs`：交互、开袋演出、福袋惊喜。
- `audio.mjs`：程序化音效（按重量变化的落袋声、玻璃压碎声、收银声等）和背景音乐；静音设置存在 localStorage `black-friday-bag-v1`。
- `tune-levels.mjs`：`node tune-levels.mjs` 用随机重启搜索每关最优装法，给出建议过关线（约 66%）和三星线（约 93%），并统计能达到三星的不同商品组合数。改关卡后跑一遍。

## 本地运行
在包含 `index.html` 的目录运行 `python -m http.server 9047 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:9047/`。静态源码和 Three.js 依赖随项目提供。

商品采用原创 3D 模型和二维格子落位。落袋冲击沿接触的商品向下传递，轻软的包装会回弹，超出承重的易碎品会留下裂纹。
